# Embed Chat — 챗봇 이용 안내 (Visitor Guide)

이 챗봇은 AI가 여러분의 질문에 실시간으로 답변하는 대화형 서비스입니다.

## 챗봇 사용 방법

1. **페이지의 챗봇 창**을 찾습니다 (보통 페이지 하단 또는 사이드에 위치)
2. 텍스트 입력창에 **질문을 입력**합니다
3. **전송 버튼**을 누르거나 **Enter 키**를 누릅니다
4. AI가 답변을 스트리밍 방식으로 **실시간 타이핑**하며 답변합니다

### 연결 상태

| 상태 표시 | 의미 |
|----------|------|
| 입력창 비활성 (회색) | 연결 중... 잠시 기다려 주세요 |
| 입력창 활성 (흰색) | 연결 완료, 메시지를 입력하세요 |
| 입력창 비활성 (연결 오류) | 네트워크 문제 — 페이지를 새로고침해 보세요 |

## 저장되는 정보

### 대화 내용

대화 중 주고받은 메시지는 세션 동안 저장됩니다. AI는 같은 대화 내에서 앞선 내용을 기억하며 답변합니다.

### 방문자 메모리

AI는 대화에서 파악한 중요한 사실을 자동으로 기억합니다.

예를 들어:
- 이름, 선호 사항, 자주 묻는 주제 등
- 다음 방문 때도 개인화된 답변을 받을 수 있습니다

> 기억된 정보는 이 서비스를 운영하는 고객사(Tenant)가 관리합니다. 정보 삭제나 수정을 원하시면 해당 웹사이트의 고객센터에 문의하세요.

## AI가 잘하는 것 / 못하는 것

**잘하는 것:**
- 이 서비스 관련 FAQ, 정책, 절차 안내
- 업로드된 문서(제품 카탈로그, 이용 약관 등) 기반의 정확한 정보 제공
- 이전 대화 맥락을 반영한 연속 답변

**한계:**
- 실시간 재고, 주문 상태 등 외부 시스템 데이터 직접 조회는 불가
- 문서에 없는 내용은 모를 수 있음
- AI 특성상 가끔 부정확한 정보를 제공할 수 있으므로 중요한 사항은 담당자에게 확인 권장

## 자주 묻는 질문

**Q. 이전 대화를 기억하나요?**
네. 같은 방문자 ID로 접속하면 AI가 이전 대화에서 파악한 정보를 바탕으로 답변합니다.

**Q. 입력한 내용이 어디에 저장되나요?**
대화 내용은 이 챗봇 서비스의 서버에 저장되며, 서비스를 운영하는 고객사가 관리합니다. 자세한 내용은 해당 사이트의 개인정보처리방침을 확인하세요.

**Q. 챗봇이 응답하지 않아요.**
페이지를 새로고침하거나, 브라우저 쿠키·캐시를 지운 후 다시 시도해 보세요. 문제가 지속되면 해당 사이트 고객센터에 문의하세요.

**Q. 개인정보 삭제를 요청하려면?**
AI가 기억한 정보 삭제는 이 챗봇을 운영하는 고객사에 요청하세요. 이 챗봇이 삽입된 웹사이트의 고객센터 또는 개인정보 담당자에게 문의하시면 됩니다.
