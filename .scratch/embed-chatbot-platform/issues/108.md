# 108 — 백엔드 Schema 정비: escalation 라우터 (와이어 불변)

Status: ready-for-agent

## Parent

[PRD-admin-orval-codegen.md](../PRD-admin-orval-codegen.md) · [ADR-0014](../../../docs/adr/0014-admin-orval-openapi-codegen.md)

## What to build

escalation(HITL) 라우터에서 `dict`/`list`/무 response인 엔드포인트(목록, 메시지, claim, typing, resolve 등)에 `Schema`를 부여한다. **와이어 포맷 불변 제약**. SSE 스트림 엔드포인트는 대상 아님(계속 손작성). 재생성으로 생성 클라이언트 타입 구체화.

## Acceptance criteria

- [ ] escalation 라우터의 dict/list/무 response 엔드포인트에 응답 Schema 부여(스트림 제외)
- [ ] **와이어 포맷 불변**: 정비 전과 동일 JSON 반환(pytest 회귀)
- [ ] 재생성 후 산출물 커밋
- [ ] 기존 escalation/hitl 백엔드 테스트 GREEN(풀스택 docker)
