## What to build

호출부 시그니처 변경 없이 모든 LLM·임베딩 호출의 토큰을 테넌트·call_type별로 record_usage에 적재.

- `UsageContext` ContextVar(tenant_id·session_id·call_type) — 진입점에서 set(chat=`chat`,
  인제스션 추출=`extraction`, OCR=`ocr`). 기존 `_current_chat_provider` 패턴 재사용.
- LLM 경계(`llm.py`): langchain 응답의 `usage_metadata`(input/output)를 읽어 record_usage.
- 임베딩 경계(`get_embeddings`): 응답 `usage`를 읽어 record_usage(call_type=`embedding`).
  usage 없는 provider는 생략(또는 추정).
- Langfuse 연동은 186(별도). 이 슬라이스는 우리 DB 적재까지.

## Acceptance criteria

- [ ] chat 1턴 → tenant·`chat`으로 TokenUsage 적재(fake LLM이 usage_metadata 반환)
- [ ] 인제스션 → `extraction`·`embedding` 적재
- [ ] usage 없는 임베딩 응답 → 안전하게 생략(크래시 없음)
- [ ] 호출부 시그니처 변경 없음, 백엔드 풀스택 GREEN
