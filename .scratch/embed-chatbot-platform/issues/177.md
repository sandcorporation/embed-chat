## What to build

랜딩 Hero에 **실제 `ChatWidget`을 mock 데이터로 구동**하는 라이브 챗봇 데모를 넣는다 — 사용자가
질문하면 AI가 토큰 스트리밍으로 마크다운 답변.

- admin `vite.config`에 `resolve.alias`(`@widget` → `../widget/src`) 추가 → 실제 `ChatWidget` import.
- mock `ChatTransport` 구현(deep module): `createEventSource`가 즉시 `connected` 발화, `postMessage`가
  질문에 맞는 스크립트 답변을 `token` 델타로 setInterval 스트리밍 후 `done`.
- 추천 질문 칩 → 매칭 답변(마크다운), 자유 입력 → 일반 답변 폴백.
- Hero 분할 레이아웃 우측에 챗봇 배치.

## Acceptance criteria

- [ ] Hero에 실제 `ChatWidget`이 렌더되고 mock 트랜스포트로 구동됨
- [ ] 추천 칩 클릭 → AI 답변이 토큰 델타로 스트리밍되고 마크다운으로 렌더
- [ ] 자유 입력 전송 → 일반 답변 스트리밍
- [ ] mock 트랜스포트 단위 테스트(`connected`→token 델타→`done`) + Hero 데모 테스트 GREEN (Docker)
