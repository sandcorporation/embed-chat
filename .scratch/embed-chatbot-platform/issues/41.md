## What to build

HITL 탭 EscalationCard에 대화 히스토리 표시 및 실시간 Visitor 메시지 수신. 백엔드(Issues 34/35)는 완료된 상태이며 프론트엔드만 수정한다.

- EscalationCard 마운트 시 `GET /api/tenant/escalations/{id}/messages`로 전체 히스토리 로드 (HITL 이전 AI 대화 포함)
- `openEscalationStream()`에 `visitor_message` 이벤트 리스너 추가
- HitlTab이 `visitor_message` 이벤트의 session_id로 해당 EscalationCard에 메시지 라우팅
- EscalationCard 내 스크롤 채팅창: role별 정렬 (user 왼쪽, assistant/human_agent 오른쪽)
- 새 메시지 수신 시 자동 스크롤

## Acceptance criteria

- [ ] EscalationCard가 열릴 때 기존 대화 히스토리가 표시된다
- [ ] Visitor가 새 메시지를 보내면 상담원 화면에 실시간으로 나타난다
- [ ] role별로 메시지가 시각적으로 구분된다
- [ ] 새 메시지 도착 시 채팅창이 자동 스크롤된다
