## What to build

`GET /api/chat/stream` 엔드포인트에서 내보내는 `connected` SSE 이벤트의 payload를 확장한다.
기존 세션(이미 ChatMessage가 존재하는 세션)에 Visitor가 재연결할 때 대화 내역과 HITL 상태를
함께 전달해, 위젯이 UI 상태를 복원할 수 있도록 한다.

**신규 세션** (ChatMessage 없음) — 기존과 동일:
```json
{ "session_id": "...", "welcome_message": "안녕하세요!" }
```

**기존 세션** (ChatMessage 존재) — 확장:
```json
{
  "session_id": "...",
  "is_hitl": true,
  "history": [
    { "role": "user",        "content": "안녕하세요" },
    { "role": "assistant",   "content": "무엇을 도와드릴까요?" },
    { "role": "human_agent", "content": "상담원입니다." }
  ]
}
```

`history` 항목은 `role` + `content`만 포함하며 `created_at` 오름차순으로 정렬한다.
기존 세션에는 `welcome_message`를 포함하지 않는다.

## Acceptance criteria

- [ ] 기존 세션(ChatMessage ≥ 1)에 재연결 시 `connected` 이벤트 payload에 `history` 배열 포함
- [ ] `history` 항목은 `role`, `content` 필드만 포함, `created_at` 오름차순 정렬
- [ ] 기존 세션에 `is_hitl: true`인 경우 payload에 `is_hitl: true` 포함
- [ ] 기존 세션에 `welcome_message` 미포함 (중복 표시 방지)
- [ ] 신규 세션에는 기존과 동일하게 `welcome_message` 포함 (회귀 방지)
- [ ] 신규 세션에는 `history`, `is_hitl` 미포함
- [ ] 모든 acceptance criteria에 대응하는 테스트가 RED→GREEN 통과
