# Entity Mention 노드 도입 (Entity와 공존, 비파괴 dual-write)

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-entity-resolution.md` (ADR-0010)

## What to build

`name` 식별키 폐기는 atomic 성격이라(조회·관계·community·검색·삭제 81곳/10파일 동시 영향) 한 번에 바꾸면 중간 스위트가 대량 red가 된다. 그래서 PRD-pgvector-retirement와 같은 **전환 패턴**으로 쪼갠다: 이 슬라이스는 **Entity Mention 노드를 기존 Entity와 공존**시키는 비파괴 추가만 한다.

- `mention_id`로 식별되는 Entity Mention 노드를 도입한다. 같은 표기라도 출처/맥락이 다르면 별개 Mention(예: 다른 문서의 "다리").
- ingest가 기존 `Entity`(name-MERGE)에 더해 Mention도 함께 생성한다(dual-write). 기존 `name` 기반 경로(조회·community·search)는 그대로 두어 **전체 스위트 green을 유지**한다.
- GraphStore 경계에 Mention upsert/조회를 추가한다(tenant 스코프).

## Acceptance criteria

- [ ] `mention_id` 식별 Mention 노드를 upsert/조회할 수 있다
- [ ] 같은 표기·다른 출처의 두 언급이 별개 Mention으로 저장된다
- [ ] ingest가 Entity와 Mention을 함께 생성한다(dual-write)
- [ ] 기존 name 기반 테스트(graph_store/search/semantic/community/delete)가 모두 green을 유지한다
- [ ] tenant 스코프가 유지된다
