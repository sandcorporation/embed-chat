## What to build

outbox를 EventBus로 흘리는 단일 relay 프로세스(management command 루프)를 만든다.

- outbox insert 시 Postgres NOTIFY(트리거 또는 record_event에서 발화) → relay가 LISTEN해 즉시 드레인.
- 드레인: 미발행 outbox 행을 **id 순서로** 읽어 `EventBus.publish(topic, key, payload)` → 성공 시 해당 행 prune(또는 published 마킹 후 정리). event_store는 건드리지 않는다.
- **catch-up sweep**: relay 부팅·재연결 시 미발행 outbox 행을 한 번 쓸어담아 발행(NOTIFY 유실 안전망).
- 단일 인스턴스라 aggregate/global 순서 보존(싱글톤 가정 명시).

## Acceptance criteria

- [ ] outbox 행이 id 순서대로 EventBus로 발행된다
- [ ] 발행 성공한 행만 prune되고 event_store는 불변
- [ ] relay가 죽어있는 동안 쌓인 미발행 행이 부팅 sweep으로 전부 발행된다(NOTIFY 유실 복원)
- [ ] NOTIFY 수신 시 폴링 없이 즉시 드레인된다
- [ ] 발행 실패 시 행이 prune되지 않고 다음 시도에 재발행된다(유실 없음)
- [ ] 실 Postgres+Redis 기반 테스트 GREEN, 백엔드 풀스택 GREEN
