# 107 — 백엔드 Schema 정비: RAG 그래프 라우터 (와이어 불변)

Status: ready-for-agent

## Parent

[PRD-admin-orval-codegen.md](../PRD-admin-orval-codegen.md) · [ADR-0014](../../../docs/adr/0014-admin-orval-openapi-codegen.md)

## What to build

RAG 문서/그래프 라우터에서 `dict`/`list`/무 response인 엔드포인트(graph search·neighbors·status·rebuild, 문서 청크 등)에 `Schema`를 부여한다. **제약: 기존 JSON 와이어 포맷을 그대로 기술 — 응답 키/구조/값 불변, 타입만 추가.** 이후 `openapi.json` 재생성으로 생성 클라이언트 타입이 좋아진다.

## Acceptance criteria

- [ ] RAG 그래프 라우터의 dict/list/무 response 엔드포인트에 응답 Schema 부여
- [ ] **와이어 포맷 불변**: 각 엔드포인트가 정비 전과 동일한 JSON을 반환(pytest 회귀로 검증)
- [ ] `scripts/gen-admin-api.sh` 재생성 시 해당 경로의 타입이 구체화되고 산출물 커밋
- [ ] 기존 RAG 관련 백엔드 테스트 GREEN(풀스택 docker)
