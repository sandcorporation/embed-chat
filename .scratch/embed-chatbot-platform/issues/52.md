# Issue 52: 임베딩 시 Document Label prefix 적용

Status: ready-for-agent
Labels: ready-for-agent

## What to build

DocumentChunk 임베딩에 Document Label(`Document.name`)을 동적으로 주입한다. 본문에 제품명이 없는 문서라도 제품명 기반 쿼리로 검색되게 하는 것이 목표다.

- ingestion 시 임베딩 입력은 `"<Document.name>: <chunk_content>"`로 구성한다. `DocumentChunk.content`에는 prefix 없이 추출 원문만 저장한다 (ADR-0006).
- retriever(`retrieve_chunks`, `retrieve_chunks_with_scores`)는 반환하는 content에 `"<document_name>: <content>"` 형태로 prefix를 동적으로 붙인다. `retrieve_chunks`는 document name 조회를 위해 select_related가 필요하다.

## Acceptance criteria

- [ ] 본문에 "FCB1010"이 전혀 없고 name이 "FCB1010"인 문서를 ingest한 뒤, "FCB1010" 포함 쿼리로 `retrieve_chunks` 했을 때 해당 청크가 검색된다
- [ ] `DocumentChunk.content`에는 label prefix가 저장되지 않는다 (raw 추출 텍스트만)
- [ ] `retrieve_chunks`와 `retrieve_chunks_with_scores` 반환 content에 document name prefix가 포함된다
- [ ] 기존 RAG 테스트(`test_ingest_*`, `test_pdf_*`)가 여전히 통과한다
