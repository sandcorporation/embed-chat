## What to build

전 메서드가 pg에서 검증되면 기본 백엔드를 pg로 전환하고 Neo4j를 제거한다(빅뱅 컷오버). 그래프 쓰기는
비동기 배치(인제스션·재구축)라 사용자 요청 경로가 아니므로, 롤링 배포 중 짧은 인제스션 동결로 발산을 피한다.

- `GRAPH_BACKEND` 기본을 pg로 전환 → 전체 백엔드 풀스택을 pg에서 GREEN 확인 후 **플래그·Neo4j 백엔드 코드 제거**.
- `NEO4J_URI/USER/PASSWORD` 설정 제거, `neo4j` 파이썬 드라이버 의존 제거.
- 모든 compose(base·dev·test·prod)에서 `neo4j`·`neo4j-test` 서비스와 `depends_on` 제거.
- README·CONTEXT 갱신 + 새 ADR(저장 엔진 Neo4j→pgvector 결정 + OCI 관리형 이식 가드: halfvec/iterative scan 비의존, 파티셔닝 훅, 선행 콘솔 점검).

## Acceptance criteria

- [ ] 기본 pg에서 전체 백엔드 풀스택 GREEN(기존 GraphStore 행동 테스트가 pg에서 통과 = 회귀 증거)
- [ ] Neo4j 설정·드라이버 의존·compose 서비스가 전부 제거됨(neo4j-test 포함)
- [ ] prod 부팅이 Neo4j 없이 정상
- [ ] 새 ADR 추가 + README/CONTEXT 갱신
- [ ] 운영 선행 점검(OCI pgvector 버전·PG 메이저)이 문서화됨
