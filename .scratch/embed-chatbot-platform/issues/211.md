## What to build

가입·비밀번호 변경에 **비밀번호 확인(재입력)** 필드와 **개인정보보호 권장 비밀번호 정책** 검증을 더한다.

- 정책 deep module(단일 검증원천): 8자 이상 + 영문·숫자·특수문자 3종 모두, 또는 10자 이상 + 2종 이상.
  위반 시 사용자 메시지, 통과 시 통과. 가입(register_tenant)과 비밀번호 변경 엔드포인트가 공유.
- 가입 폼·비밀번호 변경 폼에 확인 필드 + 정책 안내 + 불일치/정책 위반 메시지 노출(백엔드 사유 그대로).
- 팀원 생성의 임시 비밀번호는 시스템 생성(강함)이라 대상 외.

## Acceptance criteria

- [x] 약한 비밀번호로 가입·비밀번호 변경 시 400 + 정책 메시지
- [x] 정책 통과 비밀번호는 정상 처리
- [x] 확인 불일치 시 클라이언트가 막고 제출 안 함
- [x] 백엔드 정책 사유가 UI에 그대로 표시
- [x] 백엔드·프론트 테스트 그린
