# per-Tenant 벡터 인덱스 격리 (가변 차원)

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-per-tenant-providers.md` (ADR-0012)

## What to build

Tenant마다 임베딩 차원이 달라지므로, 단일 전역 벡터 인덱스(고정 차원)를 **per-Tenant 격리 인덱스**로 바꾼다. Neo4j 벡터 인덱스가 (label, property)당 고정 차원이라 섞인 차원을 담을 수 없기 때문.

- 전역 `text_unit_embedding`/`mention_embedding` → per-Tenant 격리(구현은 per-Tenant 라벨/프로퍼티).
- search/ingest가 해당 Tenant 인덱스를 타깃.

## Acceptance criteria

- [ ] 서로 다른 차원의 두 Tenant가 각자 인덱스에서 정확히 검색된다
- [ ] 한 Tenant의 차원 변경이 다른 Tenant 인덱스에 영향을 주지 않는다(교차 오염 없음)
- [ ] 기존 단일 차원(1024) Tenant의 검색이 회귀 없이 동작한다
- [ ] ingest·Local Search·Entity 검색이 Tenant 인덱스를 올바르게 사용한다
- [ ] 테스트: 서로 다른 차원 두 Tenant의 격리·검색을 Neo4j 실물로 통합 검증
