Status: ready-for-agent

## What to build

django-ninja OpenAPI 스키마를 **실행 중 서버 없이** 파일로 덤프하는 관리 커맨드. orval 입력 + 드리프트 기준이 되는 `openapi.json`을 리포에 커밋한다.

커맨드는 `config.api.api.get_openapi_schema()`를 호출해 JSON으로 직렬화·파일 출력한다. 모든 실행은 docker(`scripts/test.sh`와 동일한 백엔드 컨테이너)로.

## Acceptance criteria

- [ ] `export_openapi` 관리 커맨드가 OpenAPI 스키마를 결정적으로 파일(`openapi.json`)로 덤프
- [ ] 출력이 유효한 OpenAPI: 최상위 `openapi`/`paths` 키 존재, admin 엔드포인트 경로(`/api/operator/...`, `/api/tenant/...`) 포함
- [ ] 서버 기동 불필요(스키마 객체 직접 호출)
- [ ] `openapi.json`이 리포에 커밋됨(orval 입력·드리프트 기준)
- [ ] pytest: `call_command("export_openapi", ...)` 후 산출 JSON에 paths가 있음

## Blocked by

None - can start immediately
