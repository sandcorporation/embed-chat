## What to build

랜딩에 지식그래프 시각화 데모 섹션을 추가한다 — 실제 `react-force-graph-2d`를 목업 데이터로 구동.

- `ForceGraph2D`를 직접 사용(`KnowledgeGraphTab`은 인증 API/router에 묶여 재사용 불가). admin의
  `toGraphData` 매핑·노드리스트·디테일 패널 레이아웃을 옮겨와 재현.
- 목업 `{nodes,edges}` 공급(데모 도메인 그래프). 노드 클릭 시 목업 이웃을 머지해 확장 연출.
- 랜딩 섹션으로 배치(소개와 Contact 사이).

## Acceptance criteria

- [ ] KG 섹션이 목업 그래프로 `ForceGraph2D`를 렌더(노드/엣지 데이터 전달)
- [ ] 노드 리스트·디테일 패널이 목업 데이터로 표시되고 노드 클릭 시 이웃 확장
- [ ] 데이터 매핑/상호작용 단위 테스트 GREEN (canvas 실렌더는 jsdom 한계 — 데이터·핸들러 수준 검증)
