# 121 — Community 서브시스템 제거, 그래프 재구축을 엔티티 해소 전용으로 축소

## What to build

Global Search가 사라졌으므로 죽은 Community 코드를 들어내되, **Local Search가 의존하는 엔티티 해소(SAME_AS)는 보존**한다.

- 그래프 재구축 잡(`rebuild_communities`)을 **엔티티 해소 전용으로 축소**: 임베딩 백필 + `resolve_equivalences` + `SAME_AS` upsert만. 연결요소 탐지 + 이름-only 요약 루프 + `upsert_community`/`clear_communities` 제거. (의미상 `rebuild_graph_entities`류로 개명 가능 — 태스크/엔드포인트 와이어 호환 유지.)
- GraphStore의 `query_community_summaries`/`upsert_community`/`clear_communities` 제거.
- Graph Freshness(stale/rebuilding/fresh)와 어드민 "그래프 재구축" 엔드포인트는 **유지**(이제 엔티티 해소 갱신 의미). 와이어 계약 불변 → orval 영향 없음.
- 엔티티 해소 특성화 테스트를 **`query_mention_same_as()` 기준으로 재배선**(현재 `query_community_summaries()` 개수로 검증 중). Global 전용 테스트(커뮤니티 생성·global_search 반환)는 삭제.

## Acceptance criteria

- [ ] 재구축 잡이 community를 만들지 않고 SAME_AS(엔티티 해소)만 생성·갱신
- [ ] `search_entities`(Local)가 SAME_AS 클러스터로 여전히 dedup(동의어 병합·동음이의 분리 유지)
- [ ] GraphStore community 메서드 제거, 잔존 참조 없음
- [ ] Graph Freshness·"그래프 재구축" 엔드포인트 정상(stale→rebuild→fresh), 와이어 계약 불변
- [ ] 엔티티 해소 테스트가 SAME_AS 단언으로 재배선되어 GREEN (동의어=쌍 생성, 무관/동음이의=미생성)
- [ ] Global 전용 테스트 삭제, 죽은 community 코드 없음
- [ ] 풀스택 pytest GREEN (`scripts/test.sh`)
