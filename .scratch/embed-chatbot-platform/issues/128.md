## What to build

OperatorDashboard(단일 뷰: 테넌트 생성 폼 + 목록 테이블)를 공유 셸 + shadcn으로 옮긴다.

- `/operator/tenants` 라우트로, 최소 사이드바(Tenants). 테넌트 생성·정지·삭제·1회성 키 표시 동작 보존.
- 생성 키 알림은 shadcn Alert/Dialog로, 목록은 shadcn Table + 상태 배지로.

## Acceptance criteria

- [ ] Operator가 공유 `DashboardLayout`(최소 nav)로 렌더, 생성/정지/삭제/키표시 동작
- [ ] 테넌트 상태(활성/정지) 배지·삭제 확인 다이얼로그 일관 스타일
- [ ] 기존 동작 단언 GREEN, `tsc`·vitest GREEN
