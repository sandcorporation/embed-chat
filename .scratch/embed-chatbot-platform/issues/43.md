# Issue 43: Frontend — ChatWidget 새로고침 시 대화 내역 및 HITL 상태 복원

Status: ready-for-agent

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-session-restore-on-reconnect.md`

## What to build

`ChatWidget`의 `connected` SSE 이벤트 핸들러를 확장해, Issue 42에서 추가된
`history` / `is_hitl` payload를 수신하면 React 상태를 복원한다.

- `data.history`가 있으면 `setMessages(data.history)`로 이전 메시지 복원
- `data.is_hitl`이 `true`이면 `setIsHitl(true)`로 HITL 모드 복원
- `data.welcome_message`가 있을 때만 환영 메시지를 messages에 추가 (기존 동작 유지)

이 세 가지 분기는 `connected` 이벤트 단 하나에서 처리되며,
별도의 추가 API 호출 없이 SSE `connected` payload만으로 복원이 완성된다.

## Acceptance criteria

- [ ] 기존 세션에 재연결 시 이전 대화 메시지가 ChatWidget에 표시된다
- [ ] 기존 세션이 HITL 모드인 경우 재연결 후 위젯이 HITL 모드로 동작한다 (AI에게 메시지를 보내지 않음)
- [ ] 기존 세션에 재연결 시 환영 메시지가 다시 표시되지 않는다
- [ ] 신규 세션에서는 기존과 동일하게 환영 메시지가 표시된다 (회귀 방지)
- [ ] `human_agent` role 메시지가 대화 목록에 올바르게 렌더링된다
