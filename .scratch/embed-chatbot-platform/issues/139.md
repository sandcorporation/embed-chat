# 139 — GET /tenant/sessions/ : 전체 세션 enrich + 3계층 정렬 + 페이지네이션

Status: ready-for-agent

## Parent

[PRD-session-console-takeover-presence.md](../PRD-session-console-takeover-presence.md)

## What to build

세션 콘솔이 쓸 전체 세션 목록 엔드포인트 `GET /tenant/sessions/`(tenant_agent_auth)를 만든다.

- **범위**: 최근창(예 최근 N시간/일) + 페이지네이션. 과거 전수는 VisitorsTab 경유(범위 밖).
- **enrich**: 각 행에 session_id·visitor_id·is_hitl·escalation 상태(있으면)·presence 활성 여부(138의 `active_sessions`)·last activity·created_at.
- **3계층 정렬**: escalation(pending→claimed) → 활성(SSE) → 나머지(최근순). 서버 정렬 또는 플래그 내려 클라 정렬(택1, 관찰 동작 동일).
- 와이어 변경 → orval 재생성 + openapi.json·generated 커밋(ADR-0014).

## Acceptance criteria

- [ ] 엔드포인트가 테넌트 세션을 최근창 + 페이지네이션으로 돌려준다
- [ ] 각 행에 escalation 상태·presence 활성·visitor_id·last activity가 enrich된다
- [ ] 정렬이 escalation(pending→claimed) → 활성 → 나머지(최근순) 계층을 따른다
- [ ] orval 재생성 + 변경분 커밋
- [ ] 정렬·페이지네이션·enrich를 실 DB+Redis로 검증하는 테스트 GREEN, 백엔드 풀스택 GREEN
