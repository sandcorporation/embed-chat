# 120 — 챗에서 Global Search/router 제거 (local 직결)

Status: ready-for-agent

## Parent

[PRD-remove-global-search.md](../PRD-remove-global-search.md) · [ADR-0016](../../../docs/adr/0016-remove-global-search-keep-entity-resolution.md)

## What to build

챗 그래프에서 local/global 분류와 Global Search 경로를 제거하고, 항상 Local Search로 직결한다. 스펙형 특정 질의는 이미 있는 원문 폴백(119)이 커버한다.

- `route_search_node`·`SearchRoute`·`global_search_node`·`search_scope` 채널·`_route_scope` 제거.
- 토폴로지: `START → local_search → call_llm → [context_sufficient=False면 source_search→call_llm] → (hitl?) → save_messages`.
- 테스트용 `_FakeChatLLM`의 `SearchRoute` 분기 제거(분류 호출이 더는 없음).
- `query_community_summaries`를 호출하던 `global_search_node`만 이 슬라이스에서 제거(나머지 community 코드 정리는 #121).

## Acceptance criteria

- [ ] 챗 그래프에 route_search·global_search 노드 없음, `search_scope` 채널 없음, START가 local_search로 직결
- [ ] "공통/전체/요약" 류 질의도 별도 분기 없이 local로 처리되어 정상 응답
- [ ] 메시지당 분류 LLM 호출이 사라짐(라우팅 LLM 콜 제거)
- [ ] 기존 Local 응답·HITL escalation·원문 폴백(119)이 그대로 동작(회귀 없음)
- [ ] `_FakeChatLLM`에서 SearchRoute 분기 제거, route 분류 테스트 삭제
- [ ] 풀스택 pytest GREEN (`scripts/test.sh`)

## Blocked by

- None - can start immediately (community 코드 정리는 #121에서)
