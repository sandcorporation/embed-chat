## What to build

모든 임베딩 호출이 LLM 호출처럼 Langfuse에 generation으로 뜨게 하는 tracer. 임베딩이 흐르는 단일
경계(get_embeddings)에, 응답마다 Langfuse generation을 발행하는 가드형 deep module을 배선한다.

- 가드형·예외안전 deep module: (model, inputs, 응답 usage, tenant_id, call_type) → Langfuse generation
  발행. Langfuse 미설정이면 완전 no-op, 예외는 흡수(임베딩/인제스션/chat를 절대 안 깸).
- get_embeddings에서 기존 TokenUsage 기록과 **나란히** 호출 — 한 지점이 인제스션·chat·reembed·
  community 임베딩을 자동 커버.
- generation payload: name "embedding", model, input(LANGFUSE_CAPTURE_CONTENT off면 마스킹), usage
  (입력 토큰 = 응답 usage.total_tokens/prompt_tokens), metadata(tenant_id, call_type). 독립 generation.
- TokenUsage 기록 의미는 불변(두 sink가 같은 응답에서 공급).

## Acceptance criteria

- [ ] get_embeddings 1회 호출 → TokenUsage 1행 + Langfuse generation 1개(중복·누락 없이)
- [ ] generation에 model·입력토큰·tenant_id·call_type이 실린다
- [ ] Langfuse 미설정이면 generation 발행 no-op(오류 없음)
- [ ] Langfuse 발행이 예외를 던져도 get_embeddings는 정상 반환(best-effort)
- [ ] LANGFUSE_CAPTURE_CONTENT off면 입력 텍스트 마스킹
- [ ] Langfuse만 Fake로, 나머지(응답·TokenUsage DB) 실제로 검증
- [ ] 전체 테스트 그린
