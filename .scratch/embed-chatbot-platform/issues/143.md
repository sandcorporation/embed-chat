## What to build

도메인 이벤트의 영구 감사 저장소와 전송 큐, 그리고 둘을 한 트랜잭션으로 기록하는 헬퍼를 만든다(deep module).

- **event_store**(영구 append-only 감사): 봉투 `{event_id, type, aggregate_id=session_id, tenant_id, occurred_at, schema_version, payload}`. 삭제·published 컬럼 없음.
- **outbox**(전송 큐): 자기완결 payload(봉투 복사) + `published_at`(부분 인덱스 `WHERE published_at IS NULL`). relay가 발행 후 prune.
- `record_event(event)`: **호출자의 트랜잭션 안에서** event_store와 outbox에 둘 다 insert. 상태 변경과 같은 atomic 단위가 되도록 설계.
- 마이그레이션 포함.

## Acceptance criteria

- [ ] event_store·outbox 테이블 + 마이그레이션
- [ ] record_event가 한 호출로 event_store·outbox에 각 1건 기록한다
- [ ] 호출자 트랜잭션이 롤백되면 event_store·outbox 둘 다 기록되지 않는다(원자성)
- [ ] 봉투 필드(event_id 유일·aggregate_id·tenant_id·occurred_at·schema_version)가 채워진다
- [ ] outbox 미발행 조회가 부분 인덱스를 탄다
- [ ] 실 Postgres 기반 테스트 GREEN, 백엔드 풀스택 GREEN
