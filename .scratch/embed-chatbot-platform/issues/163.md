## What to build

엔티티 중심 Local Search 경로를 pg 백엔드로 동작시킨다 — Mention 저장(임베딩 포함) + SAME_AS
동치 엣지 + `search_entities`(어휘 ∪ 의미 검색 → SAME_AS 클러스터 dedup). flag=pg 게이팅 유지.

- `kg_mention_d{dim}`(차원 라우팅, `tenant_id`+`embedding`+name/type/description) + HNSW.
- SAME_AS는 정적 공유 엣지 테이블(`mention_id` 참조).
- 메서드(pg): `ensure_mention_vector_index`·`upsert_mention`·`query_mentions`·`mention_embeddings`·`mentions_without_embedding`·`set_mention_embedding`·`upsert_mention_same_as`·`query_mention_same_as`·`search_entities`.
- 어휘 검색은 `ILIKE`(현 `toLower CONTAINS` 치환), 의미 검색은 mention HNSW, dedup은 현 Python union-find 그대로.

## Acceptance criteria

- [ ] 동음이의(맥락 다른 같은 표기) Mention이 분리 유지된다
- [ ] 임베딩 없는 Mention 백필(`mentions_without_embedding`→`set_mention_embedding`)이 동작한다
