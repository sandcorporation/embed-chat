## What to build

어드민에 Knowledge Graph 인스펙터 탭을 만들고, 옛 "RAG 테스트" 패널을 폐기한다.

- TenantDashboard에 새 탭 **"🕸️ 지식그래프"**(KnowledgeGraphTab). 검색 전 빈 상태 + 안내 문구.
- 검색 입력 → `/rag/graph/search` → 노드-엣지 그래프 렌더(react-force-graph 의존성 추가).
- 노드 클릭 → `/rag/graph/neighbors` → 기존 뷰에 병합(점진 확장) + 선택 노드 디테일 패널(name/type/description/source docs).
- DocumentsTab에서 "RAG 테스트" 패널 제거. api.js `queryDocuments` 제거, `searchGraph`/`graphNeighbors` 추가.
- "청크 보기"/신선도/재구축은 유지.
