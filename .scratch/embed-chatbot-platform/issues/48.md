# Issue 48: PaddleOCR 서비스 Docker 통합

Status: ready-for-agent
Labels: ready-for-agent

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-ocr-rag.md`

## What to build

bt-editor의 `paddle_service/` 디렉토리를 embed-chat 루트로 복사하고, Docker 스택에 통합한다.

변경 범위:
- `paddle_service/app.py`: `lang="korean"` → `lang="ch"`, GPU 폴백(CPU 자동 전환) 추가
- `docker-compose.yml`: `paddle-ocr` 서비스 추가 (GPU 선택적)
- `docker-compose.test.yml`: `paddle-ocr-test` 서비스 추가 (CPU 전용), `api-e2e`/`worker-e2e`/`test` 서비스의 `PADDLE_OCR_URL` env 주입
- `backend/config/settings/base.py`: `PADDLE_OCR_URL = os.getenv("PADDLE_OCR_URL", "http://paddle-ocr:8080")` 추가
- `.env.example`(없으면 생성): `PADDLE_OCR_URL=http://paddle-ocr:8080` 문서화

## Acceptance criteria

- [ ] `paddle_service/` 디렉토리가 embed-chat 루트에 존재한다
- [ ] `paddle_service/app.py`가 `lang="ch"`를 사용하고, GPU 없을 때 CPU로 폴백한다
- [ ] `docker-compose.yml`에 `paddle-ocr` 서비스가 포함된다
- [ ] `docker-compose.test.yml`에 `paddle-ocr-test` 서비스가 포함되고 healthcheck가 통과한다
- [ ] `PADDLE_OCR_URL` 설정이 `base.py`에 존재한다
- [ ] `GET http://localhost:18080/health` → `{"status": "ok"}` (prod compose 기준)
