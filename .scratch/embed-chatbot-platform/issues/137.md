[PRD-hitl-business-hours.md](../PRD-hitl-business-hours.md)

## What to build

테넌트가 상담 가능 시간을 어드민에서 설정하도록, 백엔드 config 와이어와 ConfigTab UI를 추가한다.

- **백엔드 config 와이어**: TenantConfig 스케줄 필드(135)를 `GET/PATCH /tenant/config/` Schema(in/out)에 노출. 와이어 변경 → `bash scripts/gen-admin-api.sh`로 orval 재생성, `admin/openapi.json`·`admin/src/generated` 변경분 함께 커밋(CLAUDE.md/ADR-0014).
- **UI**: ConfigTab의 **상담 전환(HITL) 서브탭**(`?section=handoff`)에 타임존 선택, 요일별 on/off + 시간창(start~end), 휴일 날짜 추가/삭제를 넣는다. 비개발자용 1줄 설명 톤 유지(예: "상담원이 응대 가능한 요일·시간. 이 시간 외에는 AI만 응답합니다"). atomic 저장(단일 "저장")·`?section=` 동기화 등 기존 ConfigTab 규약 보존.

## Acceptance criteria

- [ ] config GET/PATCH가 타임존·요일별 시간창·휴일을 주고받는다
- [ ] orval 재생성 + openapi.json·generated 변경분 커밋
- [ ] handoff 서브탭에서 타임존·요일창·휴일을 편집하고 저장하면 payload에 반영된다
- [ ] 1줄 친절 설명 + 기존 aria-label·data-testid·atomic 저장·`?section=` 보존
- [ ] admin vitest·tsc GREEN, 백엔드 풀스택 GREEN
