## What to build

문서 업로드 시 텍스트를 추출하고 LLM으로 Entity/관계를 뽑아 GraphStore에 기여하는 GraphIngester를 만든다. 기존 벡터 청크 인제스션을 대체.

- 텍스트 추출 단계는 기존 재사용(PDF는 OCR fallback, 이미지는 OCR, TXT 그대로).
- 추출 텍스트 → LLM Entity/관계 추출 → GraphStore에 노드/관계 upsert(출처 Document + tenant_id 기록).
- 추출 LLM은 플랫폼 전용 모델(env, Tenant chat model과 분리), `apps/agent/llm` 경계 경유.
- `Document.status`: pending→processing→ready→failed (추출 기준).
- **이 이슈의 초기 TDD는 실제 LLM(OpenRouter) 호출로 진행**해 추출 프롬프트가 실제 모델에서 의미 있는 트리플을 내는지 검증한다(추출 품질은 Fake로 검증 불가). 확정된 결정적 회귀 테스트의 LLM 처리 방침은 별도 합의(CLAUDE.md 정책과 조율).

## Acceptance criteria

- [ ] 문서를 업로드하면 텍스트 추출 → Entity/관계가 그래프에 생성된다
- [ ] 본문에 제품명이 없어도 제품명이 Entity로 잡힌다(예: 파일명/레이블 기반)
- [ ] 각 노드/관계에 출처 Document와 tenant_id가 기록된다
- [ ] 추출 호출이 `apps/agent/llm` 경계를 통한다
- [ ] 실제 OpenRouter로 추출 결과의 타당성을 검증한다(초기 TDD)
- [ ] Document.status가 추출 완료 시 ready가 된다
