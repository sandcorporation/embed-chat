## What to build

HitlTab을 **세션 콘솔**로 확장한다. escalation 전용 목록 대신 전체 세션을 3계층으로 보여주고, 아무 세션이나 골라 takeover/채팅할 수 있게 한다.

- **목록**: `GET /tenant/sessions/`(139)로 escalation(pending→claimed) → 활성(SSE) → 나머지(최근창, 페이지네이션) 3계층 렌더. 각 행에 visitor_id·상태 배지(escalated/active/idle)·last activity.
- **라이브 갱신**: 기존 escalation SSE 스트림이 받는 `session_connected`/`session_disconnected`(138)와 `hitl_new`로 목록을 폴링 없이 재정렬/갱신.
- **takeover/채팅**: 세션 클릭 → escalation 있으면 기존 채팅(claim/message/resolve), 없으면 `POST .../takeover`(140) 후 채팅 진입.
- **딥링크 URL** 보존(ADR-0017). 상단 escalation 카드의 기존 claim/message/typing/resolve 동작 보존.

## Acceptance criteria

- [ ] 콘솔이 escalation → 활성 → 나머지 3계층으로 세션을 렌더한다
- [ ] 각 세션에 상태 배지·visitor_id·last activity가 보인다
- [ ] 연결/해제 이벤트로 활성 계층이 폴링 없이 라이브 갱신된다
- [ ] 미escalation 세션 클릭 시 takeover 후 채팅에 진입한다
- [ ] escalation 세션의 기존 claim/message/resolve·딥링크 동작이 보존된다
- [ ] admin vitest·tsc GREEN
