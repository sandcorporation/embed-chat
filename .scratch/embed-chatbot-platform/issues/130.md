## What to build

리디자인으로 바뀐 네비게이션(탭 버튼 → 사이드바 링크 + URL)에 맞춰 e2e 스펙과 남은 테스트를 정리한다.

- Playwright 스펙의 탭 클릭 셀렉터 → 사이드바 링크/직접 URL 방문으로 갱신. 자원 딥링크(visitor/session/escalation) 시나리오 추가.
- 옛 `styles.ts` 잔존 사용 점검·제거(마이그레이션 완료분).
- 다크/라이트 토글 스모크(선택).

## Acceptance criteria

- [ ] e2e가 사이드바/URL 네비게이션으로 통과(탭 버튼 의존 제거)
- [ ] 자원 딥링크 e2e 시나리오 1개 이상(예: 세션 상세 URL 직접 방문)
- [ ] 마이그레이션 끝난 섹션에서 옛 `styles.ts` 의존 없음
- [ ] admin vitest·`tsc`·e2e GREEN(풀스택)
