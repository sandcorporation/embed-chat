## What to build

랜딩 페이지 후속 다듬기(사용자 피드백).

- **KG 줌 제한**: 너무 가깝거나 멀면 그래프가 안 보이던 문제 → `minZoom`/`maxZoom`(0.8~4) 클램프
  + `onEngineStop`의 `zoomToFit`으로 로드 시 자동 프레이밍.
- **common-sense 예시 교체**: FCB1010 MIDI 컨트롤러 → **무선 이어폰**(제품 설명서 → 이어폰 →
  배터리·노이즈 캔슬링·방수, 클릭 시 충전 케이스·주변 소리 모드·IPX4로 확장).
- **모던 리디자인**: 인디고 그라데이션 Hero·그라데이션 타이틀·소프트 섀도 카드·hover 리프트.
  투박한 파란밑줄 링크 제거(색상만, 밑줄 없음), Contact는 라벨+값 카드. 위젯 채팅 마크다운 링크도
  인디고·밑줄 제거. 추천 칩·데모 박스·KG 패널 섀도/라운드 통일.
