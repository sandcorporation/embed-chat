# Issue 50: PDF OCR Fallback — 단어 수 < 50일 때 PaddleOCR 재시도

Status: ready-for-agent
Labels: ready-for-agent

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-ocr-rag.md`

## What to build

`PDFIngester.extract_text()`에서 pymupdf 추출 후 단어 수가 `PDF_OCR_FALLBACK_MIN_WORDS`(=50) 미만이면 PaddleOCR로 재시도한다.

변경 범위:
- `backend/apps/rag/ingesters.py`:
  - `PDF_OCR_FALLBACK_MIN_WORDS = 50` 상수 추가
  - `_ocr_pdf(file_bytes: bytes) -> str`: fitz로 각 페이지를 PNG 이미지로 렌더링 → paddle OCR 순차 호출 → 텍스트 합산
  - `PDFIngester.extract_text()`: pymupdf 추출 후 단어 수 체크, 미달 시 `_ocr_pdf()` 호출
- `backend/tests/test_rag.py`:
  - `test_pdf_ocr_fallback_used_when_text_too_sparse`: 텍스트 없는 이미지만 있는 PDF(최소 구성) 업로드 → OCR로 추출된 텍스트가 청크에 존재

## Acceptance criteria

- [ ] 텍스트 레이어가 없는(스캔) PDF 업로드 시 `status=ready`이고 OCR 텍스트 청크가 존재한다
- [ ] 정상 텍스트 PDF(단어 수 ≥ 50)는 pymupdf 경로를 그대로 사용한다 (OCR 미호출)
- [ ] `PDF_OCR_FALLBACK_MIN_WORDS = 50` 상수가 코드에 존재한다
