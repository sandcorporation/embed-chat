## What to build

상담 가능 시간 판정을 캡슐화한 순수 함수 `business_hours.is_open(config, now_utc) -> bool`과, 이를 떠받칠 TenantConfig 스케줄 필드를 만든다.

- **스케줄 필드(TenantConfig + 마이그레이션)**: 타임존(IANA 문자열, 예 `Asia/Seoul`), 요일별 시간창(월~일 각 on/off + start~end 1구간), 휴일 예외 날짜 리스트(요일 무관 강제 휴무). 구조화 JSON 필드로 저장(관계형 모델 아님).
- **is_open 판정**: `now_utc`를 테넌트 타임존으로 변환 → 그 날짜가 휴일이면 closed → 아니면 해당 요일 on/off와 시간창으로 판정.
- **opt-in / 기본 24/7**: 스케줄 미설정(타임존·시간창 비어 있음)이면 항상 True(하위호환).

이 슬라이스는 모델·마이그레이션·순수 함수까지다. 그래프 게이팅(136)·UI(137)는 별도.

## Acceptance criteria

- [ ] TenantConfig에 타임존·요일별 시간창·휴일 날짜 필드 추가 + 마이그레이션
- [ ] `is_open`이 UTC→테넌트 타임존 변환을 반영한다(UTC/KST 경계 케이스 포함)
- [ ] 요일 on/off와 시간창 경계(start/end)를 올바로 판정한다
- [ ] 휴일 날짜는 요일 설정을 덮어써 강제 closed
- [ ] 스케줄 미설정이면 항상 open(24/7)
- [ ] 고정 `now_utc`를 주입하는 결정적 단위 테스트 GREEN, 백엔드 풀스택 테스트 GREEN
