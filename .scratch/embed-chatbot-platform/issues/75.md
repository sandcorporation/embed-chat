# OCR 재추출 후 잔여 깨짐 Text Unit 청크 드롭

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-garbled-pdf-ocr-fallback.md`

## What to build

OCR 재추출을 거친 뒤에도 일부 청크가 여전히 깨진 경우, 그 청크를 Text Unit으로 저장하지 않고 드롭한다(citation 오염의 최종 방어선).

- `ingest_to_graph`에서 `chunk_text` 산출 청크 각각에 슬라이스 1의 `is_garbled(chunk)`를 적용해, 깨진 청크는 `upsert_text_unit` 대상에서 제외한다.
- 드롭은 Text Unit 저장에만 적용한다. Entity/관계 추출(`extract_graph`) 입력은 OCR 재추출본 전체를 그대로 사용한다(엔티티는 출처로 검증되는 해석이므로 별도 취급).

이로써 Local Search의 근거 문맥(Text Unit content)에는 읽을 수 있는 정상 텍스트만 남는다.

## Acceptance criteria

- [ ] OCR 후에도 일부 청크가 깨진 문서를 인제스션하면, 깨진 청크는 Text Unit으로 저장되지 않는다
- [ ] 같은 문서의 정상 청크는 정상적으로 Text Unit으로 저장된다
- [ ] 청크 보기(`/documents/{id}/chunks`)에 정상 텍스트 청크만 노출된다
- [ ] Entity 추출 입력은 드롭과 무관하게 OCR 재추출본 전체를 사용한다
- [ ] 슬라이스 1의 `is_garbled` 함수를 재사용한다(중복 정의 없음)
- [ ] 통합 테스트: 부분 복원 fixture(정상 청크 + 잔여 깨짐 청크 혼합)로 깨진 청크 미저장을 검증한다. 임베딩·Neo4j·OCR 실제 객체 + `apps/agent/llm` 경계만 Fake
