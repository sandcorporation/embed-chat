## What to build

테넌트가 OCR(Vision) Provider를 어드민에서 설정·검증·모델조회할 수 있게 백엔드 API를 확장하고
admin 클라이언트를 재생성한다.

- `TenantConfigOut`/`TenantConfigIn`에 ocr_* 추가(out은 api_key 마스킹).
- `update_config`가 ocr_* 저장 + `ocr_api_key` 암호화 + 변경 시 connectivity 검증(`_validate_changed_provider`에 `kind="ocr"`).
- 모델 목록 엔드포인트가 `kind="ocr"` 허용 — LLM-style `/models`(type="" → OpenRouter; embed만 ollama 특례).
- OpenAPI 변경 → `bash scripts/gen-admin-api.sh`로 orval 재생성, `admin/openapi.json`·`admin/src/generated` 함께 커밋(ADR-0014).

## Acceptance criteria

- [ ] ocr_* 라운드트립: 저장·조회 시 키는 마스킹되고 저장은 암호화된다
- [ ] OCR Provider 변경 시 connectivity 검증(실패 시 명확한 에러)
- [ ] `kind="ocr"` 모델 목록 조회가 동작(type별 정규화)
- [ ] orval 재생성분(openapi.json·generated)이 커밋됨, pre-commit 드리프트 훅 통과
- [ ] admin/embed provider 테스트를 prior art로 한 ocr 테스트 GREEN, 백엔드 풀스택 GREEN
