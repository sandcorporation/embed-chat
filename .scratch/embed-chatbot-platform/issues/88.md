# HITL 토글 — 불리언으로 에이전트 그래프 분기

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-widget-brand-hitl-toggle.md`

## What to build

Tenant가 HITL(사람 상담원 전환) 사용 여부를 고를 수 있게 한다. `TenantConfig.hitl_enabled`(기본 True)에 따라 **에이전트 그래프 토폴로지와 call_llm 스키마를 다르게 컴파일**한다.

- HITL-ON: 기존 그래프(`HITLResponse` → escalation | save).
- HITL-OFF: **response-only 스키마** call_llm → 곧장 save_messages. escalation 노드 없음 → needs_hitl을 구조적으로 표현 불가(전환 멘트 누수 차단). 시스템 프롬프트에 "사람 연결 불가" 보조 억제.
- `run_chat_agent`가 `config.hitl_enabled`로 `build_graph` 분기.

## Acceptance criteria

- [ ] `hitl_enabled` 기본 True라 기존 HITL 동작·테스트가 유지된다
- [ ] HITL-OFF에서 Fake가 needs_hitl=True를 강제해도 escalation이 생성되지 않고 assistant 메시지가 저장된다
- [ ] HITL-OFF에서 "상담원" 키워드 입력 시 AI가 답변하고 대기에 갇히지 않는다
- [ ] HITL-OFF 응답에 지키지 못할 전환 멘트가 없다
- [ ] HITL-ON에서 escalation·웹훅 흐름이 그대로 동작한다(회귀)
- [ ] 테스트: 토글별 그래프 동작을 fake_chat_llm.override로 검증
