## What to build

인제스션이 벡터 청크를 만들지 않고 Knowledge Graph만 구축하도록 전환한다(dual-write 종료).

- `ingest_document`: 텍스트 추출(PDF/OCR/이미지 유지) → 곧장 `ingest_to_graph`. `Document.status`(processing→ready/failed)는 그래프 인제스션 경로가 소유. `DocumentIngester`는 텍스트 추출 책임만 유지(청크 생성/임베딩 제거).
- Document Label 수정(PATCH name): 청크 재임베딩 대신 **이름 변경 + 대표 Entity 재시드 + Graph Freshness stale**. `reembed_document` 태스크/청크 재임베딩 함수 제거.

## Acceptance criteria

- [ ] 업로드 시 벡터 청크(DocumentChunk)가 더 이상 생성되지 않는다
- [ ] 업로드 시 그래프 Entity/Text Unit이 생성되고 Document.status가 ready가 된다
- [ ] 인제스션 실패 시 status=failed + error_message
- [ ] PATCH name이 이름을 바꾸고 대표 Entity를 재시드하며 Graph Freshness를 stale로 만든다(재임베딩 없음)
- [ ] chat/검색/청크 인스펙터가 그대로 동작한다
