## What to build

테넌트가 어드민 콘솔에서 자기 세션의 GraphRAG 검색 과정(어떤 청크가 검색됐는지)을 보게 한다.
Langfuse(206)는 오퍼레이터 전용이라 테넌트는 못 본다 — 테넌트 경로가 따로 필요하다.

핵심: 검색 결과는 사라진 게 아니다. `_clear_transient`는 *휴지(최신)* 체크포인트의 rag_chunks만
비우고, 체크포인트 **히스토리의 중간 단계**(검색 직후)엔 그대로 남아 있다. 그러니 새 저장·스키마
변경 없이, 히스토리에서 **턴별 검색 결과를 추출해 노출**만 하면 된다.

- 딥모듈: thread_id → 턴별 `{user_message, chunks, chunk_count}` (히스토리에서 복원, 휴지가 비어도).
- 어드민 세션 엔드포인트(테넌트 스코프) — 세션의 턴별 검색 결과 반환. orval 재생성 + openapi/generated 커밋.
- 어드민 UI: 세션 상세에서 턴별 "검색된 근거(청크)"를 표시.
- 체크포인트 슬림화(`_clear_transient`)·prefix 캐시 설계는 **불변** — 그래프 상태/프롬프트 안 건드림.

## Acceptance criteria

- [ ] 딥모듈이 히스토리에서 턴별 검색 청크를 복원한다(휴지 체크포인트가 rag_chunks=[]여도)
- [ ] GET 세션 retrievals 엔드포인트가 테넌트 스코프(다른 테넌트 세션은 404)
- [ ] 어드민 콘솔에서 세션의 턴별 검색 결과가 보인다
- [ ] 체크포인트 슬림화·prefix 캐시 동작 불변(기존 테스트 그린)
- [ ] 백엔드(딥모듈·엔드포인트) + 프론트(표시) 테스트 그린, orval 재생성 커밋
