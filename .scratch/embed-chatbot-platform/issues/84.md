# Tenant Slug — 공개 URL용 고유·URL-safe 식별자

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-public-slug-access.md` (ADR-0011)

## What to build

Tenant에 표시명(`name`)과 분리된 공개 URL 식별자 **Tenant Slug**를 추가한다. `/chatbot/{slug}/`에 쓰이며 전역 고유·URL-safe다. Tenant가 어드민에서 직접 설정·변경하되, 변경 시 기존 임베드 URL이 끊긴다는 경고를 받는다.

- slug 형식 검증(소문자 영숫자+하이픈), 전역 unique, 예약어 차단(`admin`·`api`·`chatbot` 등 라우트 충돌 방지).
- 표시명은 그대로 두고 slug만 분리.
- slug → Tenant 해석 헬퍼(후속 슬라이스의 연결 경로가 사용).

## Acceptance criteria

- [ ] Tenant에 slug 필드가 있고 표시명과 독립적이다
- [ ] slug는 전역에서 unique하며 중복 등록이 거부된다
- [ ] 형식 위반(대문자·공백·특수문자)이 거부된다
- [ ] 예약어(admin·api·chatbot 등)가 slug로 거부된다
- [ ] Tenant가 어드민에서 slug를 설정·변경할 수 있다
- [ ] slug 변경 시 "기존 임베드 URL이 끊긴다" 경고가 노출된다
- [ ] slug로 Tenant를 조회하는 해석 경로가 존재한다
- [ ] 테스트: slug 검증(형식·예약어·unique)은 결정적 단위, 설정/변경은 API 통합
