## What to build

Playwright e2e 스펙이 issue 84~112의 API/UI 변경을 반영하지 못해 stale다. 112에서 e2e 백엔드 스택을 재빌드해 돌린 결과, **실패가 전부 stale 스펙 탓**(admin 마이그레이션은 브라우저에서 정상 동작 확인)임이 드러났다. 스펙을 현재 계약에 맞춘다.

갱신 대상:
- **visitors-tab.spec.js**: `createVisitorSession`이 폐지된 `/api/embed/token`(+`visitor_context`)를 호출. 새 방식은 `GET /api/chat/stream?slug=<slug>&visitor_id=<vid>`로 세션 생성(`X-Session-Id` 헤더). setup에서 tenant slug를 설정해야 함(`PATCH /api/tenant/slug/`).
- **hitl.spec.js**: 위젯 escalation 헬퍼가 embed_token/visitor_context 경유. 공개 slug URL 흐름으로.
- **widget.spec.js**: 동일(embed_token/visitor_context 제거).
- **tenant-agent.spec.js**: config 저장 테스트의 `button:has-text("저장")`가 A1에서 추가된 `Slug 저장` 버튼과 모호 → exact 셀렉터로.

## Acceptance criteria

- [ ] visitors-tab.spec가 slug 기반 stream으로 세션 생성, 전체 GREEN(풀스택 e2e)
- [ ] tenant-agent.spec의 config 저장이 exact 셀렉터로 GREEN
- [ ] hitl.spec·widget.spec가 공개 slug URL 흐름으로 갱신·GREEN
- [ ] e2e 러너 이미지 재빌드 후 `docker compose -f docker-compose.test.yml run --rm e2e` 통과
- [ ] embed_token·visitor_context 참조가 e2e/tests에서 사라짐
