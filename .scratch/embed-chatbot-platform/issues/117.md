## What to build

ConfigTab의 LLM·Embedding 섹션에 "모델 불러오기" 버튼을 추가하고, 조회 결과로 모델 select를 채운다. 저장 실패(provider 검증 거부) 시 에러를 노출한다.

- LLM 섹션 "모델 불러오기" → 115 엔드포인트를 폼 현재 값(kind=llm)으로 호출 → 결과를 **model_id·extraction_model 드롭다운에 공유**.
- Embedding 섹션 "모델 불러오기" → kind=embed로 호출 → **embed_model 드롭다운**.
- free-text 폴백 공존, **저장된 현재 값은 목록에 없어도 항상 옵션 유지**.
- 조회 실패 시 에러 메시지, 저장(=update_config 검증 실패) 시 4xx 에러 노출.
- api 파사드에 모델 조회 함수 추가, 백엔드 스키마 변경분 재생성(`scripts/gen-admin-api.sh`).

## Acceptance criteria

- [ ] LLM "모델 불러오기"가 엔드포인트(kind=llm)를 호출하고 model_id·extraction_model select를 채움
- [ ] Embedding "모델 불러오기"가 kind=embed로 호출하고 embed_model select를 채움
- [ ] free-text 입력 유지, 저장값이 목록에 없어도 옵션으로 보존
- [ ] 조회 실패·저장 검증 실패 시 에러 메시지 표시
- [ ] 파사드 함수 추가 + 생성 클라이언트 재생성(드리프트 없음)
- [ ] vitest: "모델 불러오기"가 호출 후 select를 채움, 저장 실패 에러 표시(생성 모듈 mock)
- [ ] admin tsc·vitest GREEN
