# 148 — console-bridge 소비자 (내구 이벤트 → 콘솔 델타)

## Parent

[PRD-eventdriven-hitl-outbox.md](../PRD-eventdriven-hitl-outbox.md)

## What to build

HITL 라이프사이클 내구 이벤트를 소비해 어드민 세션 콘솔의 라이브 델타를 발행하는 소비자(group=`console-bridge`)를 만든다.

- `SessionEscalated`·`EscalationClaimed`·`SessionTakenOver`·`EscalationResolved` → `hitl:{tenant}` 채널에 콘솔 갱신 델타 발행(기존 `publish_hitl_new` 등과 호환되는 형태로, 콘솔이 목록을 재정렬·갱신).
- 콘솔 스냅샷은 `GET /tenant/sessions/`(권위 DB) 그대로 — 이 소비자는 델타만.
- 소비자만 — 생산자 연결은 컷오버(151). 검증은 **버스에 이벤트 주입** + `hitl:{tenant}` 구독으로.

## Acceptance criteria

- [ ] 4개 라이프사이클 이벤트가 `hitl:{tenant}`에 콘솔 델타를 발행한다
- [ ] 델타 형태가 기존 HitlTab SSE 핸들러가 이해하는 계약과 호환된다
- [ ] 멱등(같은 이벤트 재전달 시 중복 발행 없음)
- [ ] 실 Redis 기반 테스트 GREEN, 백엔드 풀스택 GREEN
