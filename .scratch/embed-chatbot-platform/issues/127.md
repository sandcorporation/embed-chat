## What to build

`/tenant/graph` 섹션을 새 셸/디자인 시스템에 통합한다. **`react-force-graph-2d` 캔버스는 재작성하지 않고** shadcn 카드/검색/패널로 감싼다.

- 검색 입력·결과·이웃 확장 컨트롤을 shadcn으로. 노드 선택 딥링크는 `?entity=` 쿼리로(가볍게).
- 그래프 status·재구축 트리거 UI 일관화.

## Acceptance criteria

- [ ] 그래프 뷰가 새 레이아웃 안에서 정상 렌더·인터랙션(검색·이웃 확장)
- [ ] `?entity=` 쿼리로 특정 엔티티 뷰 딥링크
- [ ] 기존 동작 단언 GREEN, `tsc`·vitest GREEN
