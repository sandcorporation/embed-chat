## What to build

chat·RAG 테스트 패널이 완전히 그래프 검색을 쓰도록 전환하고, 더 이상 쓰이지 않는 pgvector 기반 RAG 경로(DocumentChunk 벡터 검색, 옛 retriever, Document Label 청크 prefix/재임베딩)를 제거한다.

- 옛 `retrieve_chunks`/`retrieve_chunks_with_scores`(pgvector) 및 DocumentChunk 벡터 retrieval 제거 또는 그래프 기반으로 대체.
- Document Label의 "청크 임베딩 prefix + 재임베딩" 메커니즘 제거(Entity 추출로 대체). Label(=Document.name)은 문서 식별명·대표 Entity로 유지.
- RAG 테스트 패널/쿼리 API가 그래프 검색을 사용.
- 죽은 코드·미사용 의존성 정리.

## Acceptance criteria

- [ ] chat과 RAG 테스트 패널이 그래프 검색만 사용한다(pgvector RAG 경로 미사용)
- [ ] 옛 DocumentChunk 벡터 retrieval/재임베딩 코드가 제거된다
- [ ] Document Label은 식별명/Entity로 유지되되 청크 prefix 메커니즘은 사라진다
- [ ] 기존 RAG 관련 테스트가 그래프 기준으로 갱신되어 통과한다
