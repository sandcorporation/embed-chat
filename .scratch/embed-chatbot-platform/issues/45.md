## What to build

기존 `MemoryTab` 컴포넌트를 `VisitorsTab`으로 재작성한다.
`TenantDashboard`에서 탭 이름을 "Memory"에서 "Visitors"로 변경하고,
기존 Memory CRUD 기능을 유지하면서 방문자 탐색 기능을 추가한다.

**레이아웃 (2-패널):**

왼쪽 패널:
- 검색 입력 + "검색" 버튼
- 컴포넌트 마운트 시 자동으로 `listVisitors()` 호출해 방문자 목록 로드
- 검색어 입력 후 버튼 클릭 또는 Enter로 재검색
- 방문자 목록 카드: `visitor_id` 표시, 클릭 시 오른쪽 패널 갱신

오른쪽 패널 (방문자 선택 전):
- "방문자를 선택하세요" placeholder

오른쪽 패널 (방문자 선택 후):
- 상단에 선택된 `visitor_id` 표시
- **세션 목록 섹션**: `listVisitorSessions()`로 불러온 세션 카드 목록
  - 각 카드: `session_id` 앞 8자, `created_at`, HITL 여부 뱃지
  - 카드 클릭 → Issue 46에서 구현할 세션 상세 패널 진입 (이 이슈에서는 클릭 핸들러 자리만 확보)
- **Memory 섹션**: 기존 MemoryTab의 memory 목록 + 수정/삭제 기능 그대로 유지

## Acceptance criteria

- [ ] 탭 이름이 "Visitors"로 표시된다

- [ ] 방문자를 클릭하면 오른쪽 패널에 세션 목록과 Memory 섹션이 표시된다
- [ ] 세션 카드에 생성일시와 HITL 뱃지가 표시된다
- [ ] 기존 Memory 수정/삭제 기능이 그대로 동작한다
- [ ] 방문자 미선택 시 오른쪽 패널에 placeholder가 표시된다
