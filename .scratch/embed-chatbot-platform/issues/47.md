## What to build

Tenant 대시보드 DocumentsTab 하단에 RAG 테스트 패널을 추가한다.

**백엔드 변경 없음** — `POST /api/tenant/documents/query` 엔드포인트는 이미 동작 중이다.

### 프론트엔드 (admin)

1. `api.js`에 `queryDocuments(agentToken, query, topK)` 추가
   - `POST /api/tenant/documents/query`에 `{query, top_k: topK}` 전송
   - `[{document_name, content, score}]` 배열 반환

2. `DocumentsTab.jsx` 하단에 RAG 테스트 섹션 추가
   - 쿼리 텍스트 입력 (`placeholder="검색어를 입력하세요"`)
   - top_k 숫자 입력 (기본값 5, 1~20)
   - "검색" 버튼 (클릭 또는 Enter로 실행)
   - 로딩 중 표시
   - 결과 카드 목록: 각 카드에 문서명, 점수(`score`, 낮을수록 유사), 청크 내용 표시
   - 결과 없음 안내 문구

### E2E 테스트

`e2e/tests/rag-test-panel.spec.js` 신규 작성:

1. **Tracer bullet**: RAG 테스트 패널 쿼리 입력이 DocumentsTab에 존재한다
2. 문서 업로드 후 관련 쿼리를 실행하면 해당 문서의 청크가 결과에 표시된다
3. 점수(`score`)가 숫자로 결과에 표시된다
4. 문서가 없을 때 쿼리를 실행하면 빈 결과 안내가 표시된다

## Acceptance criteria

- [ ] DocumentsTab 하단에 쿼리 입력 + 검색 버튼이 렌더된다
- [ ] 검색 후 각 결과에 문서명, 점수, 청크 내용이 표시된다
- [ ] Enter 키로 검색이 실행된다
- [ ] top_k 값을 변경할 수 있다

- [ ] E2E Tracer Bullet 테스트가 GREEN이다
