## What to build

세션의 "활성(SSE 연결됨)" 여부를 자가치유 방식으로 추적하는 presence 모듈과, 이를 갱신·통지하는 SSE 훅을 만든다.

- **presence 모듈(deep module)**: 테넌트별 Redis sorted set(score=now, member=session_id). `mark_active(tenant, session)`, `active_sessions(tenant) -> set`(score가 임계 이내인 것만), 임계 경과분 정리. 진실원천이며 끊김 시 자연 소멸(워커 비정상 종료에도 자가치유).
- **SSE 갱신**: 방문자 SSE 스트림 루프의 keepalive 지점에서 presence 갱신. 스트림에 tenant_id를 흘려 presence·이벤트에 사용.
- **이벤트 push**: SSE 연결 시작/종료 전이에서 `session_connected`/`session_disconnected`를 **기존 `hitl:{tenant}` 채널**에 publish(어드민 콘솔이 이미 구독 → 새 인프라 없음).

## Acceptance criteria

- [ ] `mark_active` 후 `active_sessions`가 해당 세션을 활성으로 돌려준다
- [ ] 갱신이 멈추고 임계 경과하면 active_sessions에서 빠진다(TTL 자가치유)
- [ ] 방문자 SSE 연결 동안 presence가 신선하게 유지된다(keepalive 갱신)
- [ ] 연결 시작/종료 시 `session_connected`/`session_disconnected`가 `hitl:{tenant}`에 publish된다
- [ ] presence 모듈·이벤트를 실 Redis로 검증하는 테스트 GREEN, 백엔드 풀스택 GREEN
