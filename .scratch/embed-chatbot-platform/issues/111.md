## What to build

생성 클라이언트가 백엔드 스키마와 어긋난 채 커밋되는 것을 **구조적으로 차단**한다. pre-commit 훅이 `scripts/gen-admin-api.sh`를 돌리고 `git diff --exit-code`로 산출물(openapi.json + 생성 클라이언트)의 최신성을 검증해, 안 돌리고 커밋하면 실패시킨다. CLAUDE.md에 재생성 규칙을 명시한다.

## Acceptance criteria

- [ ] pre-commit 훅이 재생성 후 `git diff --exit-code`로 드리프트 검출(스테일 산출물 커밋 차단)
- [ ] 훅은 docker로 codegen 실행(CLAUDE.md "도구는 docker" 규칙과 정합)
- [ ] CLAUDE.md에 "백엔드 Ninja Schema/엔드포인트 변경 시 `scripts/gen-admin-api.sh` 재생성·커밋" 규칙 추가
- [ ] 드리프트가 있을 때(스키마만 바꾸고 재생성 안 함) 훅이 실패함을 확인
