## What to build

HITL 라이프사이클 내구 이벤트를 소비해 방문자에게 실시간 신호를 발행하는 소비자(group=`visitor-bridge`)를 만든다 — 방문자 SSE의 **단일 원천**.

- `SessionEscalated`·`SessionTakenOver` → `session:{id}` 채널에 `hitl_start` 발행.
- `EscalationResolved` → `session:{id}`에 `hitl_end` 발행.
- 기존 `publish_hitl_start`/`publish_hitl_end`의 페이로드와 동일하게(방문자 위젯 계약 불변).
- 소비자만 — 생산자 연결은 컷오버(151). 검증은 **버스에 이벤트 주입** + `session:{id}` 구독(redis_subscribe)으로.

## Acceptance criteria

- [ ] 주입된 SessionEscalated/TakenOver가 `session:{id}`에 hitl_start를 발행한다
- [ ] 주입된 EscalationResolved가 `session:{id}`에 hitl_end를 발행한다
- [ ] 발행 페이로드가 기존 위젯 계약과 동일하다
- [ ] 멱등(같은 이벤트 재전달 시 중복 발행 없음)
- [ ] 실 Redis 기반 테스트 GREEN, 백엔드 풀스택 GREEN
