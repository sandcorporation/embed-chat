# 37 — Visitors 탭 — 세션 히스토리 드릴다운

Status: ready-for-agent

## Parent

`.scratch/embed-chatbot-platform/PRD-conversation-visibility.md`

## What to build

Visitors 탭에서 Visitor를 클릭하면 해당 Visitor의 세션 목록과 대화 상세를 드릴다운으로 볼 수 있도록 한다. 새 API 두 개 추가: `GET /api/tenant/visitors/{visitor_id}/sessions/` → `[{id, created_at, ended_at, is_hitl, message_count}]`, `GET /api/tenant/sessions/{session_id}/messages/` → `[{role, content, created_at}]`. UI: Visitor 클릭 → 세션 목록 화면(뒤로 버튼), 세션 클릭 → 대화 상세 화면(뒤로 버튼).

## Acceptance criteria

- [ ] `GET /api/tenant/visitors/{visitor_id}/sessions/` 가 해당 Visitor의 세션 목록을 최신순으로 반환
- [ ] `GET /api/tenant/sessions/{session_id}/messages/` 가 세션의 ChatMessage를 시간순으로 반환
- [ ] 타 Tenant의 Visitor/Session 접근 시 404 반환
- [ ] Visitors 탭에서 Visitor → 세션 목록 → 대화 상세 드릴다운이 동작함
