## What to build

전자상거래법 제10조·정보통신망법·개인정보보호법에 따른 사업자 정보 표시 의무 대응.

- **사업자 정보 footer**: 상호·대표자·사업자등록번호·주소·전화·이메일·개인정보보호책임자를 모든
  페이지 하단에 표시(`SiteFooter`). 값은 `business.ts` 한 곳에서 관리. 통신판매업신고번호는 유료
  판매 개시 시 `salesNo`에 넣으면 자동 노출(현재 미신고로 생략).
- **개인정보처리방침(`/privacy`)·이용약관(`/terms`) 페이지**: widget 멀티페이지 엔트리
  (privacy.html·terms.html), 표준 템플릿에 플랫폼 특성(채팅 메시지·Visitor Memory 수집, LLM
  provider 위탁 등) 반영. nginx `location=/privacy·/terms` 추가. footer에서 링크.
