# 위젯 브랜드 텍스트 — 헤더 타이틀

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-widget-brand-hitl-toggle.md`

## What to build

Tenant가 위젯 헤더 상단에 표시할 브랜드 **텍스트**(`TenantConfig.brand_name`)를 설정한다(이미지 로고 아님). 브랜드 텍스트가 메인 타이틀이 되고, AI/사람 상태는 보조 텍스트+점으로 강등된다.

- `brand_name`을 SSE `connected` 이벤트 payload로 전달(welcome_message와 동일 경로).
- 위젯 헤더: 브랜드 텍스트 = 메인, 상태("AI 상담"/"상담원 연결 중") = 보조. 비면 기존처럼 상태만.

## Acceptance criteria

- [ ] Tenant가 어드민에서 brand_name을 설정·수정할 수 있다
- [ ] connected 이벤트 payload에 brand_name이 포함된다(비면 미포함/빈 값)
- [ ] 위젯 헤더가 brand_name을 메인 타이틀로, AI/사람 상태를 보조로 표시한다
- [ ] brand_name이 비면 기존처럼 상태 텍스트만 보인다
- [ ] 테스트: connected payload에 brand_name 포함 여부를 Redis 구독으로 검증

## Blocked by

None - can start immediately
