## What to build

빌드된 그래프가 LLM에 보내는 messages를 FakeLLM로 캡처해, 안정 prefix 불변식을 그래프 종단에서
잠그는 tracer. 캡처 하네스 + 핵심 플로우(HITL on/off · 멀티턴)를 end-to-end로 검증한다.

- conftest `_FakeChatLLM`에 호출별 `(schema_name, messages)` 캡처 리스트 추가(4종 구조화 호출 공통).
  기존 결정적 응답 동작은 불변 — 캡처는 부수기록.
- `run_chat_agent_async`(빌드된 그래프 ainvoke) 구동으로:
  - HITL-on(HITLResponse)·HITL-off(PlainResponse) 두 경로의 `messages[0]`(system) byte-동일.
  - 멀티턴(같은 세션 2턴)에서도 `messages[0]` 불변(history 누적해도 prefix 동일).
  - 휘발성(RAG·메모리)은 `messages[0]`에 부재, `messages[-1]`(trailing)에 존재 + UNTRUSTED 격리.

## Acceptance criteria

- [ ] 캡처 하네스가 호출 시 messages를 기록한다(하네스 자체 검증)
- [ ] HITL-on/off 두 플로우의 system prefix byte-동일
- [ ] 멀티턴에서 system prefix 불변
- [ ] 휘발성은 system 부재 · trailing 턴 존재(UNTRUSTED 유지)
- [ ] production 코드 변경 없음(테스트·conftest 한정)
- [ ] 전체 테스트 그린
