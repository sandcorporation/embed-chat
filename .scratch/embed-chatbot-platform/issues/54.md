# Issue 54: Admin UI — 업로드 레이블 입력 + 목록 인라인 편집

Status: ready-for-agent
Labels: ready-for-agent

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-document-label.md`

## What to build

Tenant 어드민 UI에서 Document Label을 지정·수정할 수 있게 한다.

- **업로드 모달**: 파일 선택 후 "Document Label" 입력 필드를 표시하고 파일명을 기본값으로 미리 채운다. Tenant가 수정 후 업로드하면 그 값이 `Document.name`이 된다.
- **문서 목록**: 각 문서 행에서 레이블을 인라인 편집(또는 편집 버튼)으로 수정 가능. 저장 시 `PATCH /rag/{document_id}` 호출 후 status가 `processing`으로 바뀌는 것을 목록에 즉시 반영한다.

## Acceptance criteria

- [ ] 업로드 모달에 파일명이 기본값으로 채워진 Document Label 입력 필드가 있다
- [ ] 모달에서 입력한 label이 업로드된 문서의 name으로 저장된다
- [ ] 문서 목록에서 레이블을 수정하면 PATCH가 호출되고 status가 `processing`으로 표시된다
- [ ] 재임베딩 완료 후 status가 `ready`로 돌아오는 것이 목록에 반영된다
