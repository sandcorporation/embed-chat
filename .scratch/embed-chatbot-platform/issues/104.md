# 104 — admin TS 토대 + auth.js→auth.ts 이관

Status: ready-for-agent

## Parent

[PRD-admin-orval-codegen.md](../PRD-admin-orval-codegen.md) · [ADR-0014](../../../docs/adr/0014-admin-orval-openapi-codegen.md)

## What to build

admin을 TypeScript로 받을 수 있게 토대를 깐다. `tsconfig.json`(allowJs로 .jsx와 공존), vite/vitest의 TS 인식. 그리고 ADR-0013의 `auth.js`(getAccess/setAccess/clearAccess/refresh/bootSilentRefresh/authFetch/onAccessChange)를 `auth.ts`로 이관하고 그 테스트(`auth.test.js`→`.ts`)를 유지한다.

이 슬라이스는 컴포넌트(.jsx)는 건드리지 않는다(allowJs로 그대로 빌드·테스트 통과). auth만 TS 선행.

## Acceptance criteria

- [ ] `tsconfig.json` 추가(allowJs, strict), vite/vitest가 TS·JSX 혼용을 빌드·실행
- [ ] `auth.js` → `auth.ts`로 이관(공개 인터페이스 동일), 타입 부여
- [ ] `auth.test.js` → TS로 이관, 기존 케이스(401 refresh→재시도, boot refresh, refresh 실패 시 access 제거) GREEN
- [ ] 기존 `.jsx` 컴포넌트·나머지 vitest가 그대로 통과(회귀 없음)
- [ ] 프론트 테스트는 docker node 컨테이너로 실행(CLAUDE.md 규칙)

## Blocked by

None - can start immediately
