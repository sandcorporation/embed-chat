# 136 — 영업시간으로 그래프 선택 게이팅 + 시간 외 안내

Status: ready-for-agent

## Parent

[PRD-hitl-business-hours.md](../PRD-hitl-business-hours.md)

## What to build

챗 에이전트 실행 시 영업시간으로 HITL 그래프를 가른다. 그래프 컴파일 인자를 `hitl_enabled = config.hitl_enabled AND business_hours.is_open(config, now_utc)`로 바꾼다. 시간 외 = `hitl_enabled=False` 그래프(plain, escalation 노드 없음 → 전환 멘트 구조적 차단). 새 억제 코드 없이 기존 두 토폴로지(ADR-0001)를 재사용한다.

시간 외(`is_open=False`)일 때, 133이 만든 **뒤쪽 컨텍스트 메시지 슬롯**에 운영 안내 텍스트("현재 상담 운영시간(…)이 아니라 상담원 연결이 어렵습니다")를 싣는다. system prefix는 불변(캐시 유지). 안내는 AI 응답으로 자연스럽게 전달된다.

## Acceptance criteria

- [ ] `config.hitl_enabled=True`라도 시간 외면 plain 그래프(escalation 노드 부재)로 실행된다
- [ ] 시간 내 + hitl_enabled면 기존 HITL 그래프(escalation 가능) 그대로
- [ ] 시간 외엔 escalation이 생성되지 않는다
- [ ] 시간 외 운영 안내가 뒤쪽 컨텍스트 메시지로 주입되고 system prefix는 불변이다
- [ ] hitl_enabled=False면 영업시간과 무관하게 기존 plain 동작 불변
- [ ] 실 그래프 빌드 + Fake LLM으로 시간 내/외 분기를 단언하는 테스트 GREEN, 백엔드 풀스택 GREEN
