Labels: ready-for-agent

## Parent

## What to build

`ingesters.py`에 `ImageIngester`를 추가하고, 이미지 파일 업로드를 백엔드·프론트 양쪽에서 지원한다.

변경 범위:
- `backend/apps/rag/ingesters.py`:
  - `ImageIngester(DocumentIngester)` 추가: base64 인코딩 → `POST {PADDLE_OCR_URL}/ocr` → 텍스트 반환
  - `MIME_TO_INGESTER`에 `image/png`, `image/jpeg`, `image/webp` 추가
- `backend/apps/rag/views.py` (또는 업로드 뷰): 허용 MIME 타입에 이미지 추가
- `admin/src/components/DocumentsTab.jsx`: `accept=".pdf,.txt,.png,.jpg,.jpeg,.webp"`
- `backend/tests/test_rag.py`: `test_ingest_image_via_ocr` 추가 (paddle-ocr-test 서비스 실제 호출)

## Acceptance criteria

- [ ] PNG 파일 업로드 시 `status=ready`, 청크 존재
- [ ] JPG 파일 업로드 시 `status=ready`, 청크 존재
- [ ] WEBP 파일 업로드 시 `status=ready`, 청크 존재
- [ ] 이미지 청크 내용에 OCR로 추출된 텍스트가 포함된다
- [ ] 프론트 업로드 input이 이미지 파일을 선택 가능하다
- [ ] 지원하지 않는 MIME(예: `image/gif`)은 400 에러를 반환한다
