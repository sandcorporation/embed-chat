## What to build

위젯을 여러 번 새로고침하면 옛/새 SSE 연결이 겹치는데, 늦게 닫히는 옛 연결의
`VisitorDisconnected`가 어드민 세션 콘솔을 "유휴"로 잘못 뒤집는다. presence를 **연결 단위로
참조 계수**해, 세션의 첫 연결(0→1)·마지막 종료(1→0) 전이에서만 connect/disconnect 이벤트를 낸다.
presence sorted-set(TTL 자가치유)은 진실원천으로 유지.

## Acceptance criteria

- [x] `register_connection`이 세션의 첫 연결에서만 True, `unregister_connection`이 마지막 종료에서만 True
- [x] 두 SSE 연결이 겹칠 때 먼저 닫힌 옛 연결은 `VisitorDisconnected`를 내지 않는다
- [x] 마지막 연결 종료 시에만 `VisitorDisconnected` 발행
- [x] 실 Redis 기반 테스트 GREEN, 백엔드 풀스택 GREEN
