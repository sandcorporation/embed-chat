# Issue 53: Document Label 수정 + 자동 재임베딩

Status: ready-for-agent
Labels: ready-for-agent

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-document-label.md`

## What to build

Tenant가 이미 업로드한 문서의 Document Label을 수정하면, 파일 재업로드나 OCR 없이 자동으로 재임베딩이 일어나 새 label 기준으로 검색되게 한다.

- `PATCH /rag/{document_id}`: 바디 `{ "name": "..." }`. 빈 name이면 400, 다른 Tenant 문서면 404. 성공 시 `Document.name` 갱신 후 재임베딩 태스크를 트리거하고 갱신된 DocumentOut 반환.
- `re_embed_document` Celery 태스크: 기존 `DocumentChunk.content`(raw)를 읽어 현재 `Document.name`으로 prefix해 임베딩만 교체한다. 텍스트 재추출/OCR 없음. status는 `pending` → `processing` → `ready`(실패 시 `failed` + error_message)로 재순환.

## Acceptance criteria

- [ ] `PATCH /rag/{document_id}`로 name을 바꾸면 status가 재순환하고 최종 `ready`가 된다
- [ ] name 변경 후 새 name 포함 쿼리로 검색하면 해당 문서 청크가 검색된다 (이전 name으로는 매칭도가 떨어진다)
- [ ] 빈 name → 400, 존재하지 않거나 타 Tenant 문서 → 404
- [ ] 재임베딩은 OCR/텍스트 재추출 없이 기존 chunk content로만 수행된다
- [ ] 재임베딩 동작이 end-to-end 테스트로 검증된다
