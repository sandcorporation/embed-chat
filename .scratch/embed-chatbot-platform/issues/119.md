## What to build

Local Search가 그래프-only로 답을 못 냈을 때(`context_sufficient=False`) 원문 `TextUnit`을 끌어와 한 번 더 시도하는 증거 기반 폴백을 챗 그래프에 단다. 스펙·수치·표처럼 추출이 버린 사실을 원문으로 회복한다.

- 새 `source_search` 노드: `GraphStore.vector_search(user_message, top_k)`로 최근접 `TextUnit.content`를 가져와 `rag_chunks`에 append(기존 청크와 중복 회피). `top_k`는 작게 캡(예: 3~5).
- `ChatState`에 `source_text_tried: bool` 추가(폴백 1회 보장 가드).
- 토폴로지: `call_llm` 후 분기 —
  - `context_sufficient == False` AND `source_text_tried == False` → `source_search` → `call_llm`(재호출, `source_text_tried=True`)
  - 그 외 → 기존 라우팅(HITL: needs_hitl ? create_escalation : save_messages / HITL-OFF: save_messages)
  - HITL·HITL-OFF 두 토폴로지 모두에 폴백 분기.
- 보강 원문은 기존 `UNTRUSTED_DATA` 구역으로 들어간다(간접 인젝션 격리 유지).
- 폴백은 메시지당 최대 1회(무한 루프 방지).

## Acceptance criteria

- [ ] 그래프엔 없고 `TextUnit`에만 있는 사실(해상도형) 질의가 **HITL/"모른다" 대신 원문으로 답함** (풀스택, 실제 Neo4j/임베딩 + Fake LLM)
- [ ] `source_search`가 `vector_search` 결과(원문 청크)를 `rag_chunks`에 보강하고 LLM 재호출
- [ ] **토큰 가드**: 그래프로 답한 happy path(`context_sufficient=True`)에선 `source_search`/`vector_search` 미호출, `rag_chunks` 불변
- [ ] 폴백 후에도 `context_sufficient=False`면 기존 경로(HITL/모름)로 정상 진행
- [ ] HITL·HITL-OFF 두 경로 모두 폴백 동작
- [ ] 보강 원문이 `UNTRUSTED_DATA` 구역에 격리되어 들어감
- [ ] `top_k` 캡으로 1회 폴백당 원문 청크 수 제한
- [ ] 풀스택 pytest GREEN (`scripts/test.sh`)
