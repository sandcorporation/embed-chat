## What to build

Fake LLM의 비-escalation 및 일반 텍스트 completion 경로를 마무리하고, qwen 의존과 우회책을 제거한다.

- Fake LLM이 `tools` 없는 일반 `/v1/chat/completions` 요청(예: Visitor Memory 추출)에 `choices[0].message.content`로 카난 텍스트(예: 빈 facts `{}`)를 반환한다.
- `widget.spec.js`의 "AI 응답이 표시된다" 테스트가 결정적으로 통과한다: 인사말 → `needs_hitl=false` → assistant 응답 표시(false escalation 없음).
- `ollama-test-init`에서 `qwen2.5:3b` pull을 제거한다(bge-m3만 유지). 단위 `test`·E2E 모두 더 이상 qwen을 호출하지 않으므로 안전.
- `hitl.spec.js`의 fresh-session 재시도 우회책을 제거하고 단순 흐름으로 정리한다(57에서 이미 결정적이므로).

## Acceptance criteria

- [ ] Fake LLM이 일반 completion 요청에 텍스트 응답을 반환하고, 메모리 추출 경로가 E2E에서 깨지지 않는다
- [ ] `widget.spec.js`의 "AI 응답" 테스트가 결정적으로 통과한다(인사 → assistant 응답)
- [ ] `ollama-test-init`이 qwen을 pull하지 않고 bge-m3만 받는다
- [ ] `hitl.spec.js`에서 fresh-session 재시도 코드가 제거되고 여전히 통과한다
- [ ] 전체 E2E 스위트가 통과한다
