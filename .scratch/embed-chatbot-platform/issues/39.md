## What to build

Knowledge Base 디버그용 RAG Query 엔드포인트. TenantAgent가 임의의 쿼리를 입력하면 Knowledge Base에서 매칭되는 DocumentChunk를 유사도 점수·문서명과 함께 반환한다.

- `POST /api/tenant/documents/query` — Body: `{ query, top_k? }`, Response: `[{ document_name, content, score }]`
- retriever에 `retrieve_chunks_with_scores()` 추가 (L2Distance 값 포함 반환)
- 기존 `retrieve_chunks()`는 그래프 노드에서 계속 사용하므로 유지

## Acceptance criteria

- [ ] `POST /api/tenant/documents/query`가 매칭 청크, 문서명, score를 반환한다
- [ ] `top_k` 파라미터로 반환 수를 제한할 수 있다 (기본값 5)
- [ ] 다른 Tenant의 청크가 결과에 포함되지 않는다
- [ ] 테스트가 실제 pgvector를 사용한다 (Mock 없음)
