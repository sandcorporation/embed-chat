## What to build

위젯 소스를 TS로 전환하고, `ChatWidget`이 트랜스포트(EventSource 생성 + 메시지 전송)를 주입받게
한다. 실제 컴포넌트를 mock 데이터로도 구동할 수 있는 토대(랜딩 데모용) + 위젯/admin 일관성.

- 위젯 `.jsx`→`.tsx`(`ChatWidget`·`Markdown`·`App`·`main`) + `tsconfig` 추가. 동작/번들 불변.
- `ChatWidget`에 주입 경계 추가(프로토타입 확정):
  ```ts
  interface ChatTransport {
    createEventSource(url: string): EventSourceLike   // addEventListener/close
    postMessage(sessionId: string, content: string): Promise<void>
  }
  ```
  기본 구현 = 현재 동작(`new EventSource` / `fetch`). 이벤트 처리 로직은 그대로, 생성·전송 지점만 주입.
- 위젯 테스트: 전역 `EventSource` 덮어쓰기 → mock 트랜스포트 주입으로 정리.
