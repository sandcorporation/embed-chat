# 34 — HITL 대화 히스토리 API + UI

Status: ready-for-agent

## Parent

`.scratch/embed-chatbot-platform/PRD-conversation-visibility.md`

## What to build

TenantAgent가 EscalationCard에서 에스컬레이션 이전 AI 대화 전체를 볼 수 있도록 한다. 새 API `GET /api/tenant/escalations/{escalation_id}/messages` 를 추가해 해당 세션의 ChatMessage를 시간순으로 반환. EscalationCard가 마운트될 때(pending/claimed 무관) 이 API를 호출해 스크롤 가능한 대화 뷰를 카드 내에 표시. role별 말풍선 스타일로 user/assistant/human_agent 메시지를 구분.

## Acceptance criteria

- [ ] `GET /api/tenant/escalations/{id}/messages` 가 해당 세션의 ChatMessage를 `[{role, content, created_at}]` 형태로 반환
- [ ] 존재하지 않는 escalation_id 요청 시 404 반환
- [ ] EscalationCard 마운트 시 히스토리가 자동 로드되어 표시됨
- [ ] pending 상태 에스컬레이션에서도 히스토리가 보임

## Blocked by

None - can start immediately
