## What to build

Langfuse를 A1에 셀프호스트하고 LLM/임베딩 경계에 Langfuse 기록을 연동(오퍼레이터 관찰·디버깅).

- compose에 langfuse-web·worker + **전용** postgres·redis·clickhouse·minio(운영 것과 분리),
  메모리 limit. NPM 별도 호스트로 오퍼레이터에게만 노출.
- Langfuse 클라이언트/설정(env: host·키·`LANGFUSE_CAPTURE_CONTENT` 본문 킬스위치).
- LLM 경계에 CallbackHandler 부착(metadata=UsageContext) + 임베딩 Langfuse SDK record.
  env 미설정 시 no-op(테스트·dev 무영향).
