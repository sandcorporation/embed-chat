## What to build

Visitor Memory 추출의 LLM 호출도 동일한 경계 모듈을 통하도록 바꾸고, 단위 테스트에서 결정적 Fake로 교체한다.

- 경계 모듈에 `complete_text(model_id, messages)` 추가. 프로덕션 구현은 기존과 동일하게 `ChatOpenAI(...).invoke(messages).content` 반환.
- Visitor Memory 추출 태스크가 이 경계를 **모듈 속성으로** 호출한다. 코드펜스 제거·JSON 파싱·`upsert_memory` 로직은 유지.
- 테스트 autouse fixture가 `complete_text`를 결정적 facts JSON 문자열을 반환하는 Fake로 교체.
- 메모리 추출 테스트를 Fake 기반으로 결정화.

## Acceptance criteria

- [ ] Visitor Memory 추출이 신설 경계 함수를 통해 이뤄지고, 태스크 내 `ChatOpenAI` 직접 생성이 제거된다
- [ ] Fake가 반환한 facts가 `upsert_memory`로 저장되는 것이 결정적으로 검증된다
- [ ] `test_memory.py`의 추출 테스트가 실제 LLM 없이 통과한다
- [ ] 프로덕션 메모리 추출 동작은 변경되지 않는다
