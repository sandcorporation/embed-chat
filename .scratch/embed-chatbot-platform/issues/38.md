# 38 — Visitors 탭 — Memory 통합

Status: ready-for-agent

## Parent

`.scratch/embed-chatbot-platform/PRD-conversation-visibility.md`

## What to build

Visitor 상세 화면(세션 목록 뷰)에 해당 Visitor의 Memory 목록을 하단에 함께 표시하고, 수정·삭제를 인라인으로 제공한다. 기존 Memory API(`GET/PATCH/DELETE /api/tenant/visitors/{visitor_id}/memory/`)를 재활용. Memory 탭의 기존 수정·삭제 로직을 Visitors 탭 Visitor 상세 뷰로 이동.

## Acceptance criteria

- [ ] Visitor 상세 화면 하단에 해당 Visitor의 Memory 목록이 표시됨
- [ ] Memory key/value 수정 후 목록에 즉시 반영됨
- [ ] Memory 삭제 후 목록에서 즉시 제거됨
- [ ] Memory가 없으면 "Memory 없음" 메시지 표시
