## What to build

VisitorsTab의 상태 드릴다운(`selectedVisitor`/`selectedSession`)을 **자원 URL 라우트로 전환**하고 shadcn으로 리스타일한다.

- `/tenant/visitors` (목록) · `/tenant/visitors/:visitorId` (세션 목록 + Memory) · `/tenant/sessions/:sessionId` (SessionDetail 대화 상세).
- 선택을 `useParams`/`useNavigate`로 — 새로고침·뒤로가기·딥링크·공유 가능.
- 목록/세션/Memory 테이블·HITL 배지를 shadcn으로.

## Acceptance criteria

- [ ] visitor/session 선택이 URL을 바꾸고, 딥링크(`/tenant/visitors/:id`, `/tenant/sessions/:id`)가 해당 뷰를 직접 렌더
- [ ] 새로고침·뒤로가기로 master-detail 탐색이 자연스러움
- [ ] Memory 조회·수정·삭제, 세션 메시지/체크포인트 조회 동작 보존
- [ ] 라우팅 테스트(param 라우트 렌더) + 기존 동작 단언 GREEN, `tsc`·vitest GREEN
