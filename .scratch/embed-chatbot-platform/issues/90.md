# ExcelIngester — xlsx·xls를 헤더-키 행별 텍스트로

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-web-excel-ingestion.md`

## What to build

Excel(xlsx·xls)을 업로드해 Knowledge Graph에 넣을 수 있게 한다. 시트를 **헤더-키 행별 텍스트**로 평탄화해 행 단위 Entity 추출에 적합하게 만든다.

- **ExcelIngester deep module**: `extract_text(file_bytes) -> str`. 첫 행=헤더(키), 각 데이터 행을 `헤더: 값` 쌍으로. 시트별 섹션(시트명 prefix). 수식은 계산값(openpyxl data_only), 빈 셀 skip. xlsx=openpyxl, xls=xlrd. 두 mime → ExcelIngester.

## Acceptance criteria

- [ ] xlsx 업로드 → status ready, Text Unit·Entity 생성
- [ ] xls 업로드도 동일하게 동작한다
- [ ] 각 행이 `헤더: 값` 텍스트로 평탄화되어 행 기반 Entity가 검색된다
- [ ] 멀티시트 워크북이 시트별 섹션으로 구분된다
- [ ] 수식 셀이 계산값으로 들어가고 빈 셀은 skip된다
- [ ] 테스트: ExcelIngester는 fixture로 순수 단위(DB 불필요), 업로드→그래프는 통합(임베딩·Neo4j 실물)

## Blocked by

None - can start immediately
