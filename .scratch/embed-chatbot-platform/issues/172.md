## What to build

스트리밍을 전면 끌 수 있는 ops 킬스위치와, 스트림 도중 에러의 graceful 처리.

- `CHAT_STREAMING_ENABLED`(기본 on) 설정. off면 챗 노드가 `complete_structured`(현행 one-shot) 경로로 — 두 경로(structured·plain) 모두.
- 스트림 도중 예외 시 `publish_error` + done 처리(위젯이 멈춤/에러 표시). 부분 출력 후 에러도 graceful.

## Acceptance criteria

- [ ] `CHAT_STREAMING_ENABLED=false`면 현행 one-shot 동작(structured·plain 둘 다)
- [ ] 스트림 중 예외 시 publish_error가 나가고 무한 대기에 빠지지 않는다
- [ ] 부분 출력 후 에러도 안전하게 종료(중복·깨짐 없음)
- [ ] 노드 테스트 GREEN, 백엔드 풀스택 GREEN
