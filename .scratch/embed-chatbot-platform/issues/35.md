# 35 — HITL Visitor 실시간 메시지

Status: ready-for-agent

## Parent

`.scratch/embed-chatbot-platform/PRD-conversation-visibility.md`

## What to build

HITL 모드에서 Visitor가 새 메시지를 보내면 상담원 화면에 실시간으로 나타나도록 한다. `POST /api/chat/message`에서 `session.is_hitl == True`일 때 `hitl:{tenant_id}` Redis 채널에 `{"type": "visitor_message", "session_id": "...", "content": "..."}` 이벤트를 발행. 어드민 EscalationCard는 기존 escalation SSE(`hitl:{tenant_id}`)를 통해 `visitor_message` 이벤트를 수신하고 해당 `session_id`와 일치하는 카드의 대화 목록에 메시지를 append.

## Acceptance criteria

- [ ] HITL 세션에서 `POST /api/chat/message` 호출 시 Redis `hitl:{tenant_id}` 채널에 `visitor_message` 이벤트가 발행됨
- [ ] 비HITL 세션에서는 `visitor_message` 이벤트가 발행되지 않음
- [ ] EscalationCard에서 visitor_message SSE 이벤트 수신 시 해당 세션의 메시지 목록에 실시간으로 추가됨
