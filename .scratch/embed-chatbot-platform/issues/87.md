# ChatRateLimiter — 공개 URL 남용·비용 고갈 가드

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-public-slug-access.md` (ADR-0011)

## What to build

공개 `/chatbot/{slug}/`가 무방비로 노출되지 않도록 메시지 경로에 경량 레이트리밋을 둔다. 스팸으로 Tenant LLM 비용을 고갈시키는 것을 막는다(하드 예산 캡은 기능 C).

- **ChatRateLimiter deep module**: Redis 기반 (tenant, visitor_id)당 분당 한도 + per-tenant 롤링 상한. 초과 시 메시지 처리 거부.

## Acceptance criteria

- [ ] (tenant, visitor_id)당 한도 내 메시지는 허용, 초과는 거부된다
- [ ] 윈도우 경과 후 다시 허용된다
- [ ] per-tenant 상한이 폭주를 차단한다
- [ ] 서로 다른 (tenant, visitor)는 독립적으로 카운트된다
- [ ] 테스트: 실제 Redis로 한도→초과→회복·격리를 결정적으로 검증
