## What to build

문서 삭제 시 그래프를 정합하게 정리한다. 공유 Entity는 보존하고, 그 문서에만 속한 노드/관계만 제거한다.

- 삭제 경로: 노드/관계의 출처 집합에서 해당 Document 제거 → 출처가 빈 노드/관계만 prune → 그래프 stale 표시(issue 64의 재구축으로 요약 갱신).
- 기존 Document 삭제 API에 연결(Text Unit·Entity·관계 정리 포함).

## Acceptance criteria

- [ ] 두 문서가 공유하는 Entity는 한 문서 삭제 후에도 남는다
- [ ] 삭제 문서에만 있던 Entity/관계/Text Unit은 제거된다
- [ ] 삭제 후 Graph Freshness가 stale이 된다
- [ ] 삭제가 tenant 스코프로만 적용된다
- [ ] 실제 Neo4j로 공유/고유 시나리오를 검증
