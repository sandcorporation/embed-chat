# 101 — 에스컬레이션 SSE silent refresh 시 재오픈

Status: ready-for-agent

## Parent

[PRD-admin-access-refresh-auth.md](../PRD-admin-access-refresh-auth.md) · [ADR-0013](../../../docs/adr/0013-admin-access-refresh-token-auth.md)

## What to build

단수명(30분) access와 장수명 SSE 연결의 화해. 에스컬레이션 스트림은 access를 쿼리 파라미터로 받아 인증하므로, access가 30분 뒤 만료되면 EventSource 재연결이 실패한다. 프론트가 silent refresh로 access를 갱신할 때 기존 EventSource를 close하고 새 access로 재오픈하도록 묶는다(전용 장수명 스트림 토큰을 새로 만들지 않음 — ADR-0013 Q7-A).

## Acceptance criteria

- [ ] access 갱신(silent refresh) 시 EscalationStream EventSource가 close→재오픈되어 새 access로 재연결
- [ ] 30분(access TTL) 경과 후에도 HITL 스트림 이벤트(hitl_new 등)가 끊기지 않고 계속 수신
- [ ] 재오픈 시 직전 연결은 정리되어 중복 연결이 남지 않음
- [ ] 프론트 vitest: 토큰 갱신 콜백이 스트림 재오픈을 트리거(이전 EventSource close + 새 토큰으로 신규 오픈)
