## What to build

chat 그래프(LangGraph)의 `retrieve_node`를 그래프 기반 검색으로 교체한다. 질의를 분류해 Local Search로 라우팅하고 그 근거로 응답한다.

- `route_search → local_search → call_llm` 구조. 라우팅은 `complete_structured`에 `search_scope`(local/global) 필드로 분류(별도 LLM 호출 없이). 이 슬라이스에서는 global은 아직 local로 처리(또는 stub), Local Search 경로를 완성.
- Local Search: 벡터 검색(issue 62) + Entity 이웃 확장 → LLM 컨텍스트.
- HITL escalation, 토큰 스트리밍, 메시지 누적/저장 등 기존 chat 동작은 그대로 보존.

## Acceptance criteria

- [ ] 엔티티 중심 질의가 그래프(엔티티 이웃 + Text Unit)를 근거로 답한다
- [ ] 본문에 제품명 없는 문서도 제품명 질의로 답 근거가 잡힌다
- [ ] HITL 트리거("상담원"/불확실)가 기존과 동일하게 동작한다
- [ ] search_scope 라우팅이 구조화 출력으로 결정된다
- [ ] RAG 테스트 패널 쿼리가 그래프 검색으로 동작한다
