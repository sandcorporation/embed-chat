## What to build

Issue 45에서 자리를 확보한 세션 카드 클릭 핸들러를 구현해 세션 상세 패널을 연다.

세션 상세 패널은 오른쪽 패널의 세션 목록/Memory 영역을 대체하며,
"← 뒤로" 버튼으로 돌아갈 수 있다.

세션 상세 패널은 두 개의 sub-tab으로 구성된다:

**대화 내역 탭:**
- `getSessionMessages()`로 불러온 메시지를 역할별 말풍선으로 표시
- `HitlTab`의 `ChatHistory` 컴포넌트와 동일한 스타일 (user: 오른쪽/파란색, assistant: 왼쪽/회색, human_agent: 왼쪽/보라색)
- 메시지가 없으면 "대화 내역 없음" 표시

**Checkpoint 탭:**
- `getSessionCheckpoint()`로 불러온 JSON을 `<pre>`에 pretty-print
- `null` 반환(404) 시 "이 세션은 AI 호출 내역이 없습니다." 안내 텍스트
- JSON 박스는 `max-height: 400px; overflow-y: auto` 스크롤 처리

## Acceptance criteria

- [ ] 세션 카드 클릭 시 세션 상세 패널이 열린다
- [ ] "← 뒤로" 버튼 클릭 시 세션 목록으로 돌아간다
- [ ] 대화 내역 탭에서 메시지가 역할별 말풍선으로 표시된다
- [ ] `human_agent` role 메시지가 올바르게 렌더링된다
- [ ] Checkpoint 탭에서 JSON이 pretty-print로 표시된다
- [ ] Checkpoint가 없는 세션(404)에서 안내 문구가 표시된다
