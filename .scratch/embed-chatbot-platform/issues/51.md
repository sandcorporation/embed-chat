## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-ocr-rag.md`

## What to build

DocumentsTab에서 각 문서의 청크 내용을 인라인으로 확인할 수 있는 기능을 추가한다.

변경 범위:
- **백엔드**:
  - `GET /api/tenant/documents/{id}/chunks` 엔드포인트 추가
  - 응답: `[{chunk_index: int, content: str}]` (embedding 제외)
  - 다른 Tenant의 문서는 404 반환
- **`admin/src/api.js`**: `listDocumentChunks(agentToken, docId)` 함수 추가
- **`admin/src/components/DocumentsTab.jsx`**:
  - 각 문서 행에 "청크 보기" 버튼 추가
  - 클릭 시 해당 행 아래에 accordion 패널 펼침
  - 청크 목록: `#인덱스 | 내용 미리보기(앞 200자)` 형태
  - 로딩·빈 상태 처리

## Acceptance criteria

- [ ] `GET /api/tenant/documents/{id}/chunks` → `[{chunk_index, content}]` 반환
- [ ] 다른 Tenant 문서 청크 조회 시 404 반환
- [ ] "청크 보기" 버튼 클릭 시 해당 문서의 청크 목록이 펼쳐진다
- [ ] 청크가 없는 문서(empty PDF 등)는 "청크 없음" 안내가 표시된다
- [ ] 다시 클릭하면 패널이 닫힌다 (toggle)
