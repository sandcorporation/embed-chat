## What to build

Community 탐지 + LLM 요약을 만들고, Global Search 경로와 Graph Freshness 상태/재구축 트리거를 추가한다.

- CommunityBuilder: tenant 그래프에 Community 탐지 + LLM Community 요약 생성(요약 LLM은 `apps/agent/llm` 경계 경유). 배치/트리거로만 실행.
- Graph Freshness 상태(`fresh`/`stale`/`rebuilding`): 문서 추가·삭제로 stale, 재구축 후 fresh. `Document.status`와 별개.
- 재구축 트리거: 업로드 후 디바운스 자동 + 어드민 수동 "재구축" 버튼. 동일 경로 단일화.
- Global Search 노드: Community 요약 map-reduce. `route_search`가 global로 분기.
- 어드민 UI: Graph Freshness 표시 + 재구축 버튼.

## Acceptance criteria

- [ ] 글로벌/요약형 질의가 Community 요약을 근거로 답한다
- [ ] 문서 추가/삭제 시 Graph Freshness가 stale이 된다
- [ ] 어드민 수동 재구축 + 디바운스 자동 재구축이 동일 경로로 동작하고 완료 시 fresh가 된다
- [ ] stale 상태에서도 직전 요약으로 Global Search가 동작한다
- [ ] 어드민에서 Freshness와 재구축 버튼이 보인다
