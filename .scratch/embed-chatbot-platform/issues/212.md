## What to build

상담원 콘솔의 SSE 스트림(`escalation_stream`)이 async 개편(ADR-0022/issue 195)에서 누락돼 여전히 sync
뷰 + 블로킹 `pubsub.listen()`(sync redis)이다. uvicorn ASGI에서 chat SSE가 겪던 바로 그 블로킹 문제로
**라이브 이벤트 전달이 안 된다.** 콘솔의 다른 갱신(에스컬레이션 목록·presence)은 폴링이 가려주지만,
폴링 대체가 없는 **visitor_message만** 눈에 띄게 깨진다(위젯 SSE는 이미 async라 상담원→위젯은 정상).

chat의 `asse_event_stream`과 동일하게 **async 뷰 + async redis pubsub 구독 + async generator**로 전환한다.
클라이언트(EventSource)·이벤트 형식(`event: <type>`)은 불변이라 어드민 프론트는 안 건드린다.

## Acceptance criteria

- [ ] escalation_stream이 async 뷰 + async redis 구독으로 전환됨(블로킹 sync listen 제거)
- [ ] hitl 채널에 발행된 visitor_message가 연결된 스트림으로 라이브 전달된다(통합 테스트)
- [ ] 토큰 인증·tenant 채널 스코프·연결 종료 정리(unsubscribe/close)는 동작 보존
- [ ] 어드민 콘솔에서 visitor 실시간 메시지가 상담원에게 보인다(배포 후 prod 검증)
- [ ] 전체 테스트 그린
