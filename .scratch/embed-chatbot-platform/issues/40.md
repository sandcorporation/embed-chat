## What to build

ChatSession의 LangGraph Checkpoint를 raw JSON으로 조회하는 엔드포인트. TenantAgent가 LLM에 실제로 전달된 state(messages, rag_chunks, system_prompt 등)를 직접 확인한다.

- `GET /api/tenant/sessions/{session_id}/checkpoint` — Response: `channel_values` raw JSON
- LLM 호출이 없었던 세션은 404 반환
- 다른 Tenant의 session_id로 조회 시 404 반환
- 기존 `_create_checkpointer()` 재사용, 조회 후 connection close

## Acceptance criteria

- [ ] `run_chat_agent()` 실행 후 GET 요청이 200과 `channel_values`를 반환한다
- [ ] 응답에 `messages`, `rag_chunks` 키가 존재한다
- [ ] LLM 호출 없는 세션에 GET 시 404를 반환한다
- [ ] 다른 Tenant 소속 session_id로 조회 시 404를 반환한다
