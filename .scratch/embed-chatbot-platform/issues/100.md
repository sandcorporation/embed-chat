# 100 — 로그아웃 3종 (기기별 / 전체 / 비번변경 자동폐기)

Status: ready-for-agent

## Parent

[PRD-admin-access-refresh-auth.md](../PRD-admin-access-refresh-auth.md) · [ADR-0013](../../../docs/adr/0013-admin-access-refresh-token-auth.md)

## What to build

다중기기 환경의 로그아웃·일괄폐기 시맨틱을 end-to-end로 완성. Operator·TenantAgent 양쪽.

백엔드: `POST .../auth/logout`(현재 Family만 폐기 + 쿠키 삭제), `POST .../auth/logout-all`(subject 전 Family 폐기 + 쿠키 삭제). 기존 `change-password` 성공 경로에 `revoke_all(subject)` 호출 추가(비번 변경 시 전 세션 무효화).

프론트: 로그아웃 버튼이 서버 폐기 호출 후 sessionStorage 정리(브라우저만 비우지 않음). 어드민 UI에 "모든 기기에서 로그아웃" 액션 노출.

## Acceptance criteria

- [ ] `logout`이 현재 Family만 폐기(다른 기기 세션 생존) + 쿠키 삭제
- [ ] `logout-all`이 subject 전 Family 폐기 + 쿠키 삭제
- [ ] `change-password` 성공 시 해당 subject 전 Family 자동 폐기(기존 세션으로 refresh 시 401)
- [ ] 프론트 로그아웃이 서버 폐기 호출 + sessionStorage access 제거
- [ ] 어드민 UI에 "모든 기기에서 로그아웃" 버튼(Operator·TenantAgent)
- [ ] 백엔드 테스트: 기기별 폐기 독립성·전체폐기·비번변경 폐기 / 프론트 vitest: 로그아웃이 폐기 호출 + 정리
