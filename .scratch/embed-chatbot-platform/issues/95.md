# 재임베딩 무중단 재구축 — Embedding Provider 변경 시

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-per-tenant-providers.md` (ADR-0012)

## What to build

Embedding Provider를 바꾸면 저장된 벡터가 새 모델의 벡터 공간과 호환되지 않으므로, 그래프 구조는 보존한 채 **재임베딩**한다. 검색 다운타임 없이 진행한다.

- 트리거: **Embedding Provider 변경**(LLM Provider 변경은 재구축 없음). 호환은 차원이 아니라 모델 정체성으로 판단.
- 비동기(Celery), `Graph Freshness=rebuilding`. 옛 인덱스/벡터가 서빙되는 동안 새 인덱스에 새 차원으로 Text Unit·Mention 재임베딩 → 원자적 swap → 옛것 폐기. 그래프 구조(Entity·관계·Community) 보존. dual-write 전환 패턴.

## Acceptance criteria

- [ ] Embedding Provider 변경이 재임베딩 재구축을 트리거한다
- [ ] LLM Provider(챗/추출) 변경은 재구축을 트리거하지 않는다
- [ ] 재임베딩 중 옛 임베딩으로 Local Search가 계속 동작한다(무중단)
- [ ] 완료 후 새 인덱스로 원자적 전환되고 옛 인덱스가 폐기된다
- [ ] 그래프 구조(Entity·관계·Community)가 보존된다(재추출 없음)
- [ ] 진행 중 Graph Freshness=rebuilding으로 표시된다
- [ ] 테스트: provider 변경→재임베딩 중 검색 동작→전환 후 새 검색, 구조 보존을 Neo4j 실물로 통합 검증
