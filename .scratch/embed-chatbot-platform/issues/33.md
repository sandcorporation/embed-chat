# 33 — LangGraph Checkpoint 도입

Status: ready-for-agent

## Parent

`.scratch/embed-chatbot-platform/PRD-conversation-visibility.md`

## What to build

`langgraph-checkpoint-postgres` 패키지를 추가하고 `PostgresSaver`를 그래프에 연결해 ChatSession 단위로 대화 state를 자동 저장·복원한다. `thread_id = session_id`로 설정. `run_chat_agent`에서 수동 히스토리 로드 코드를 제거하고 Checkpoint가 대화 연속성을 관리하도록 변경. ChatMessage 저장(save_messages_node)은 유지. DB 전체 초기화(truncate)를 전제로 기존 세션 migration 불필요.

## Acceptance criteria

- [ ] `run_chat_agent`를 동일 session_id로 두 번 호출했을 때 두 번째 호출에서 첫 번째 대화 내용이 context로 전달됨 (Checkpoint 복원 검증)
- [ ] `run_chat_agent`에서 `ChatMessage`를 직접 조회해 history를 구성하는 코드가 제거됨
- [ ] `langgraph-checkpoint-postgres` 가 requirements.txt에 추가됨
- [ ] Checkpoint 테이블이 마이그레이션 또는 setup()으로 생성됨
