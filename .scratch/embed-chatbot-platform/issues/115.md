## What to build

어드민이 "모델 불러오기"로 호출하는 엔드포인트. 폼의 현재 provider 값(미저장 포함)으로 114의 `list_provider_models`를 호출해 모델 목록을 반환한다.

- `POST /api/tenant/providers/models` `{kind, type, base_url, api_key, model}` → `{models:[id]}` 또는 4xx + 에러 메시지. tenant_agent_auth.
- **마스크 키 처리**: `api_key`가 `********`면 저장된 키를 복호화해 사용(update_config 마스크 처리와 동일). 새 키를 입력했으면 그 값 사용.
- 응답엔 모델 id만 — 키·시크릿 절대 미노출.

## Acceptance criteria

- [ ] 유효 provider로 호출 시 `{models:[...]}` 반환
- [ ] api_key가 마스크면 저장된 키로 조회(키 재입력 불필요)
- [ ] 새 api_key를 보내면 그 키로 조회
- [ ] provider 조회 실패(키/URL 오류) 시 4xx + 사람이 읽는 에러 메시지
- [ ] 응답에 키·시크릿이 포함되지 않음
- [ ] tenant_agent_auth 강제(미인증 401)
- [ ] pytest: 목록 반환·마스크키→저장키·실패 4xx (provider HTTP는 Fake)
