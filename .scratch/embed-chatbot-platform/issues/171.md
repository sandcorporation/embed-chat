## What to build

HITL이 꺼진 테넌트의 답변 경로(`call_llm_plain` / `PlainResponse`)도 동일하게 토큰 스트리밍한다.
170에서 만든 `stream_structured` 경계와 노드 패턴(델타 publish + 폴백 게이팅 + 자동 저하)을 재사용.

- 스키마 필드 순서: `PlainResponse` = `context_sufficient` → `response`.
- `call_llm_plain`: 170과 동일한 스트림 소비·게이팅·자동 저하·publish_done.

## Acceptance criteria

- [ ] HITL-off 종단 패스에서 `publish_token`이 델타로 여러 번 호출된다
- [ ] HITL-off 폴백 패스에서 스트리밍 억제(중복 출력 0)
- [ ] needs_hitl이 구조적으로 없는 PlainResponse 의미 보존(전환 멘트 누수 불가)
- [ ] 노드 테스트 GREEN, 백엔드 풀스택 GREEN
