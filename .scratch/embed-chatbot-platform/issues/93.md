# Embedding Provider + OpenAI-호환 임베딩 클라이언트

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-per-tenant-providers.md` (ADR-0012)

## What to build

LLM Provider와 독립된 **Embedding Provider**를 도입한다(Claude는 임베딩 부재로 제외). 임베딩 클라이언트를 OpenAI-호환으로 통일해 prod(호스팅)·dev(ollama)가 동일 경로를 탄다.

- **Embedding Provider 설정**: `{type: openai|custom, base_url, api_key, embed_model, embed_dim}`. 키 암호화·마스킹(92 재사용).
- **임베딩 클라이언트**: `get_embeddings`를 ollama 네이티브 `/api/embed` → OpenAI-호환 `/v1/embeddings`로 전환, provider-설정 가능.
- **dev 기본**: 로컬 ollama의 `/v1/embeddings`. **prod 폴백 없음** — Embedding Provider 미설정 시 인제스션·검색 불가(온보딩 필수).

## Acceptance criteria

- [ ] Embedding Provider 설정을 저장·교체할 수 있고 타입에 anthropic이 없다
- [ ] `get_embeddings`가 OpenAI-호환 `/v1/embeddings`로 임베딩을 획득하고 차원이 일치한다
- [ ] LLM Provider와 독립적으로 설정된다(Claude 챗 + OpenAI/Custom 임베딩 조합 가능)
- [ ] dev는 로컬 ollama `/v1/embeddings`로 키 없이 동작한다
- [ ] prod에서 Embedding Provider 미설정 시 인제스션·검색이 명확히 거부/안내된다
- [ ] 테스트: 임베딩 클라이언트는 ollama 실물로 결정적, 독립 설정·미설정 거부는 통합
