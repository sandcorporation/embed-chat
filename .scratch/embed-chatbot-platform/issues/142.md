## What to build

이벤트 전송을 추상화한 좁은 `EventBus` 포트와 Redis Streams 어댑터를 만든다(deep module). 추후 Kafka 어댑터가 드롭인되도록 인터페이스는 브로커-중립으로.

- 포트: `publish(topic, key, payload)` + consumer-group 소비(`consume(topic, group, consumer) -> 메시지 iterator`) + `ack(message)` + dead-letter 이동.
- Redis Streams 어댑터: `XADD`(payload는 봉투 JSON), consumer group(`XGROUP`/`XREADGROUP`), `XACK`, `XPENDING`/`XCLAIM`(재처리), dead-letter 스트림 이동.
- key는 봉투에 보존(Redis 단일 스트림에선 미사용, Kafka 파티션키로 예약).

## Acceptance criteria

- [ ] publish→consume(group)→ack 왕복이 동작한다(실 Redis Streams)
- [ ] 같은 group의 두 consumer가 메시지를 분할 소비한다
- [ ] ack 안 한 메시지가 XPENDING에 남고 XCLAIM으로 재처리된다
- [ ] dead-letter 이동 API가 메시지를 dead-letter 스트림으로 옮긴다
- [ ] 포트 인터페이스는 Redis 전용 개념을 노출하지 않는다(Kafka 교체 가능)
- [ ] 실 Redis Streams 기반 테스트 GREEN, 백엔드 풀스택 GREEN
