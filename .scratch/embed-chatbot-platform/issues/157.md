## What to build

OCR을 단일 포트 뒤로 숨기고 기존 Paddle 동작을 그 포트로 감싼다(동작 불변 리팩터). 이후 슬라이스가
같은 포트에 Vision 어댑터를 꽂을 수 있게 한다.

- 포트 `OCRBackend.transcribe(image_bytes, mime_type) -> str`.
- `PaddleOCR` 어댑터 — 기존 Paddle HTTP 호출을 래핑.
- 팩토리 `get_ocr_backend(config)` — 현 시점엔 항상 Paddle(dev/test). config 인자는 받되 미사용(다음 슬라이스에서 vision 분기).
- ingester 주입: `extract_text(file_bytes, ocr)`로 시그니처 변경. 이미지 ingester와 PDF 스캔/깨짐 폴백이 `ocr.transcribe`를 호출. 인제스션 태스크가 백엔드를 만들어 주입.
- 거대한 스캔 PDF 통제: `OCR_MAX_PAGES`(기본 30) 초과 페이지는 OCR 생략(경고 로그).

## Acceptance criteria

- [ ] 이미지(PNG·JPEG·WEBP) 업로드가 포트 경유 Paddle OCR로 동일하게 추출된다
- [ ] 스캔/깨진 PDF가 포트 경유 페이지별 OCR 폴백으로 복구되고 is_garbled 드롭이 유지된다
- [ ] 멀쩡한 텍스트 PDF는 OCR 없이 PyMuPDF로 처리된다(불필요한 OCR 호출 0)
- [ ] `OCR_MAX_PAGES` 초과 시 OCR 호출 수가 상한으로 제한된다
- [ ] 기존 test_rag OCR 테스트가 새 포트 주입에 맞게 갱신되고 dev/test=Paddle 실제 객체로 GREEN, 백엔드 풀스택 GREEN
