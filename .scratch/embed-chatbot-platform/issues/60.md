## What to build

GraphRAG의 토대 — Neo4j(Community)를 도커 스택에 띄우고, 모든 그래프 접근을 `tenant_id`로 강제 스코프하는 GraphStore 경계 모듈을 만든다.

- docker-compose(dev/prod/test)에 Neo4j 컨테이너 추가. 테스트 스택은 결정적 검증을 위해 실제 Neo4j 인스턴스 사용. Python neo4j 드라이버 의존성 추가, 연결 설정(env).
- GraphStore deep module: `tenant_id`를 모든 메서드에 강제로 받는 단일 진입점. 최소 능력으로 시작 — Entity upsert(출처 Document 기록 포함), tenant 스코프 Entity 조회.
- tenant_id 없이는 그래프에 닿을 수 없도록 인터페이스 설계.

## Acceptance criteria

- [ ] Neo4j 컨테이너가 dev/prod/test 스택에 있고 healthcheck 통과
- [ ] GraphStore로 tenant A의 Entity를 upsert 후 tenant A로 조회하면 반환된다
- [ ] tenant B로 조회하면 tenant A의 Entity가 보이지 않는다 (격리)
- [ ] 실제 Neo4j 테스트 인스턴스로 검증(NO MOCK), 여러 번 실행해도 결정적
- [ ] GraphStore 메서드가 tenant_id를 강제한다(누락 불가)
