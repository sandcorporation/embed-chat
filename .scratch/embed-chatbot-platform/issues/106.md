## What to build

orval을 도입해 103의 `openapi.json`에서 105의 mutator를 쓰는 **평범한 TS 클라이언트 함수**를 생성하고, 그 산출물을 커밋한다. 재생성은 docker 단일 명령으로.

- orval 설정: 입력=`openapi.json`, mutator=105 custom instance, 출력=admin 생성 디렉터리(커밋).
- `scripts/gen-admin-api.sh`: ① 백엔드 docker로 `export_openapi` → openapi.json ② admin node docker로 orval. 모두 docker.
- react-query 미사용(평범한 함수). 생성 함수는 데이터 반환·throw 계약.

## Acceptance criteria

- [ ] `orval.config`가 openapi.json을 입력, mutator를 custom instance로 지정, admin에 TS 클라이언트+타입 생성
- [ ] `scripts/gen-admin-api.sh`가 export→orval을 docker로 일괄 실행
- [ ] 생성된 클라이언트가 mutator를 거쳐 호출(타입 컴파일 통과)
- [ ] 생성물이 리포에 커밋됨
- [ ] 스크립트 재실행 시 산출물이 동일(결정적) — `git diff` 없음
- [ ] 생성 함수 자체는 미테스트(orval 신뢰, 드리프트는 111에서 강제)
