## What to build

이벤트 파이프라인 런타임 프로세스를 dev/prod/e2e 컴포즈와 배포에 추가한다 — 풀 파이프라인 e2e(150·151)가 실제 프로세스로 돌 수 있게.

- 신규 서비스: `relay`(싱글톤) + `worker-webhook` + `worker-visitor-bridge` + `worker-console-bridge` + `worker-presence-bridge`. 소비자는 모두 `consume_events --group=<name>`(코드 단일, 인자만 다름).
- docker-compose.yml(prod)·docker-compose.dev.yml·docker-compose.test.yml(e2e 스택)에 추가. worker-chat 패턴(env·depends_on·재시작) 재사용.
- relay는 단일 인스턴스로 고정(순서 보존), 소비자는 필요 시 수평 확장 가능하게.

## Acceptance criteria

- [ ] dev/prod/e2e 컴포즈에 relay + 소비자 4 프로세스 추가
- [ ] 각 프로세스가 부팅되어 Redis/Postgres에 연결되고 헬스 확인된다
- [ ] relay는 단일 인스턴스, 소비자는 group별 독립 프로세스
- [ ] e2e 스택에서 풀 파이프라인(생산→relay→버스→소비자)이 기동된다
