# Web URL 인제스션 — 명시적 URL을 Document로

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-web-excel-ingestion.md`

## What to build

Tenant가 명시한 URL(들)을 fetch해 Knowledge Graph에 넣는다(재귀 크롤 아님). 각 URL이 하나의 Document가 된다.

- **Document Source**: Document에 파일/URL 소스 구분 + URL 저장. 인제스션 태스크가 분기(파일=디스크, URL=fetch).
- **WebIngester deep module**: URL → fetch(HTML) → 메인 콘텐츠 추출(보일러플레이트 제거) → 텍스트. fetch와 추출 분리(추출은 fixture HTML로 격리 테스트).
- **URL 추가 API + 수동 재-fetch**: URL(들)로 Document 생성+인제스션. Document Label 기본값=페이지 title 또는 URL. 어드민 "다시 가져오기"로 재-ingest.

## Acceptance criteria

- [ ] URL을 추가하면 fetch·본문 추출 후 그래프에 기여하고 Local Search로 검색된다
- [ ] 각 URL이 별도 Document(출처·삭제 단위)다
- [ ] nav·footer 보일러플레이트가 제거되고 본문만 추출된다
- [ ] Document Label 기본값이 페이지 title 또는 URL이다
- [ ] 접근 불가 URL은 Document status=failed + error_message
- [ ] 수동 재-fetch가 기존 기여분을 교체한다
- [ ] 파일 업로드 경로는 회귀 없이 동작한다
- [ ] 테스트: WebIngester 추출은 fixture HTML 결정적, fetch는 로컬 HTTP fixture, 인제스션은 통합
