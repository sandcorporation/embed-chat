## What to build

주제범위 3개 필드를 테넌트 admin config 엔드포인트로 읽고 쓰게 한다.

- config GET/PATCH에 `topic_scope_enabled`·`scope_description`·`scope_refusal_message` 노출.
- 검증: `topic_scope_enabled=True`로 저장하려면 `scope_description`이 비어 있지 않아야 한다(에러 안내).
- orval 재생성(ADR-0014): 백엔드 Ninja Schema 변경이므로 admin OpenAPI·생성 클라이언트 재생성,
  `admin/openapi.json`·`admin/src/generated` 함께 커밋.

## Acceptance criteria

- [ ] config GET이 3개 필드를 반환
- [ ] config PATCH로 3개 필드 설정/조회 왕복
- [ ] 토글 ON + 빈 scope_description 저장 시 검증 에러
- [ ] orval 재생성 + openapi.json·generated 커밋
- [ ] config API 테스트(set/get + 검증) 그린
