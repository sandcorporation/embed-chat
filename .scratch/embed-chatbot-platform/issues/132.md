# 132 — 설정 항목에 비개발자용 친절 설명 추가

Status: ready-for-agent

## Parent

[PRD-config-subtabs-friendly.md](../PRD-config-subtabs-friendly.md) · [ADR-0012](../../../docs/adr/0012-per-tenant-llm-embedding-providers.md)

## What to build

각 세부 탭과 기술 항목에 **평이한 한국어 설명**을 붙여 비개발자가 무엇을 입력해야 할지 알게 한다(무엇인지 + 모르면 어떻게).

- 각 세부 탭 상단에 1줄 인트로(예: AI 모델 → "챗봇을 움직이는 AI 엔진을 고릅니다").
- 기술 항목 helper text(예시):
  - **API Key**: "OpenAI·Claude 같은 AI 서비스에서 발급받은 비밀 키예요. 모르면 담당 개발자에게 'OpenAI API 키'라고 요청하세요."
  - **Embedding Provider**: "올린 문서를 AI가 검색하도록 '숫자 지문'으로 바꾸는 엔진. 보통 LLM과 같은 회사 걸 쓰면 됩니다."
  - **Base System Prompt**: "봇의 성격·말투·역할을 정하는 지시문. 예: '친절한 쇼핑몰 상담원처럼 존댓말로 답하라.'"
  - **Provider 타입 / Base URL / 차원 / 신원검증 / Slug** 등도 한 줄씩.
- 톤: 용어를 모르는 운영자도 행동할 수 있게. 동작·레이아웃 변경 없음(텍스트만 추가).

## Acceptance criteria

- [ ] 4개 세부 탭에 인트로 1줄씩
- [ ] 주요 기술 항목(API Key·Embedding·System Prompt·Provider 타입·Base URL·차원·신원검증·Slug 등)에 평이한 helper text
- [ ] 설명 텍스트가 렌더됨을 확인하는 테스트 1~2개(예: API Key 설명/Embedding 설명 노출)
- [ ] 기존 동작·aria-label·data-testid 불변, admin vitest·tsc GREEN
