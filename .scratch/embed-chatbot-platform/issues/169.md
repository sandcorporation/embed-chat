## What to build

'AI 모델' 설정 탭을 상태별로 재구성한다 — 미설정이면 OpenAI 한방 카드, 설정됐고 3종 동일하면 컴팩트
요약, 섞였으면 고급만. 기존 vendor별 3종 상세는 "고급 설정"으로 접는다.

- **상단 상태별 렌더**(`_config_out` 필드 사용):
  - 미설정(`llm_provider_type === ''`) → **OpenAI 한방 카드**: 키 한 칸 + "시작하기" → quick-setup 호출 → 성공 시 화면이 요약으로 전환. 카드 문구 env별(prod="필수", dev="키로 바로 설정 또는 고급에서 기본").
  - 3종 동일 타입(`llm===embed===ocr`, 비빈값) → **컴팩트 요약 카드**("AI 제공자: OpenAI · 챗 X · 임베딩 Y · OCR Z" + [고급에서 변경]).
  - 섞임 → 요약 없음, 고급 기본 펼침.
- **고급 설정(접힘)**: 기존 LLM·Embedding·OCR 3종 상세 섹션 그대로(회귀 없이 이동). dev의 `기본(OpenRouter)` 옵션 유지.
- non-blocking — 어느 상태든 고급으로 상세 설정 도달 가능.

## Acceptance criteria

- [ ] `llm_provider_type=''`면 한방 카드가 보이고, 키 입력→시작하기가 quick-setup을 호출한다
- [ ] 3종 동일 provider면 컴팩트 요약 카드, 섞이면 요약 없음+고급 펼침
- [ ] 기존 LLM·Embedding·OCR 상세가 고급 설정 안에 그대로 동작(회귀)
- [ ] 한방 성공 시 요약 상태로 전환된다
- [ ] admin vitest GREEN
