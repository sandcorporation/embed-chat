# 조회·search·neighbors를 Mention/Entity 단위로 + name 경로 제거 (dual-write 종료)

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-entity-resolution.md` (ADR-0010). 78 재분할의 마지막 조각 — 전환 완료.

## What to build

엔티티 검색·이웃·인스펙터·삭제를 raw name이 아니라 **Entity Mention과 resolved Entity(SAME_AS 클러스터)** 단위로 동작하게 하고, 78에서 두었던 dual-write를 끝내 **기존 `name` 기반 Entity 경로를 제거**한다.

- `search_entities`·`neighbors`·`graph_search`가 resolved Entity(동치 클러스터) 단위로 반환(어휘∪벡터 검색 신호는 유지, 집계만 Entity 단위).
- 문서 삭제(prune)·조회가 Mention 식별 기준으로 일관.
- 공존하던 `name`-MERGE Entity 경로를 제거하고 관련 기존 테스트를 Mention/Entity 모델로 마이그레이션.

## Acceptance criteria

- [ ] 엔티티 검색이 표기변이 중복 대신 하나의 resolved Entity를 반환한다
- [ ] 동음이의는 검색·인스펙터에서 별개 Entity로 구분된다
- [ ] 어휘 부분일치·의미(벡터) 매칭 능력이 유지된다(검색 회귀 없음)
- [ ] 문서 삭제가 Mention 기준으로 출처 prune을 일관되게 수행한다
- [ ] dual-write가 종료되고 name 기반 Entity 경로가 제거된다
- [ ] 마이그레이션된 기존 테스트 전부 green
