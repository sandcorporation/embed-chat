## What to build

문서 삭제·레이블 변경·임베딩 Provider 변경(재임베딩)의 그래프 반영을 pg 백엔드로 완성한다.
이로써 GraphStore의 모든 공개 메서드가 pg 경로를 갖는다. flag=pg 게이팅 유지.

- 메서드(pg): `delete_document`(TextUnit·Mention 제거 + freshness stale)·`reseed_document_label`·`recreate_vector_indexes`(차원 변경 시 인덱스/테이블 재생성).
- 재임베딩 잡(`reembed_tenant`)이 pg에서 동작 — 차원 변경 시 새 차원 테이블로 swap.

## Acceptance criteria

- [ ] flag=pg에서 문서 삭제 시 그 문서의 TextUnit·Mention이 사라지고 freshness=stale
- [ ] 레이블 변경이 대표 Mention 재시드 + stale 반영
- [ ] 임베딩 차원 변경 시 인덱스/테이블 재생성 + 재임베딩이 무중단 swap된다
- [ ] 기존 삭제·재임베딩 행동 테스트가 flag=pg에서 GREEN, 백엔드 풀스택 GREEN
