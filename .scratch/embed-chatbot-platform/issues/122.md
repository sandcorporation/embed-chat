## What to build

리디자인의 기반 슬라이스. 디자인 시스템을 깔고, 사이드바 셸을 만들고, 상태 탭을 중첩 URL 라우트로 전환한다. **섹션 내부는 기존(인라인 스타일) 그대로** 새 셸 안에 렌더한다(동작 불변, 리스타일은 후속 슬라이스).

- **Tailwind + shadcn 셋업**: Tailwind config/postcss, shadcn `components.json` + `cn` util + CSS 변수(light/dark) + ThemeProvider/다크 토글. docker `vite build`로 빌드되는지 확인.
- **`DashboardLayout` 셸(deep module)**: 사이드바(브랜드 + nav 항목 + active 하이라이트) + 상단 바(계정/로그아웃/로그아웃-올) + `<Outlet/>`. nav 항목을 prop으로 받아 Operator/Tenant 공유.
- **라우팅 전환**: 상태 탭 → 중첩 라우트. `/tenant`→redirect `/tenant/documents`, `/operator`→redirect `/operator/tenants`. 각 섹션이 라우트(섹션 컴포넌트는 기존 것 그대로 마운트).
- 라이트 기본 + 다크 토글 동작.

## Acceptance criteria

- [ ] Tailwind+shadcn 빌드 통과(docker `vite build`), `tsc` 클린
- [ ] `DashboardLayout`이 사이드바+상단바+Outlet을 렌더, Operator/Tenant가 동일 셸 사용(nav만 다름)
- [ ] 각 섹션이 URL을 가짐(`/tenant/{documents,graph,visitors,config,agents,hitl}`, `/operator/tenants`), 새로고침·뒤로가기·딥링크 동작(nginx 폴백 활용)
- [ ] `/tenant`→documents, `/operator`→tenants 리다이렉트
- [ ] 다크 토글로 라이트/다크 전환
- [ ] 기존 동작(로그인/로그아웃, 섹션 내용) 회귀 없음 — 섹션 내부는 미변경
- [ ] 라우팅 테스트(딥링크가 해당 섹션 렌더, 리다이렉트, active 상태) + 기존 vitest GREEN(필요 시 라우터 래퍼)
