## What to build

문서 텍스트를 Text Unit 노드로 그래프에 저장하고, bge-m3 임베딩을 Neo4j 벡터 인덱스에 넣어 벡터 검색 primitive를 제공한다.

- 인제스션 시 텍스트를 Text Unit으로 분할 저장(출처 Document·tenant_id), 추출된 Entity와 연결.
- bge-m3(ollama, 1024차원) 임베딩을 Neo4j 네이티브 벡터 인덱스에 저장(임베딩은 실제 객체로 결정적).
- GraphStore에 tenant 스코프 벡터 검색 메서드 추가(쿼리 임베딩 → 최근접 Text Unit).
- RAG용 pgvector는 이 경로로 대체됨(컷오버는 issue 66).

## Acceptance criteria

- [ ] 인제스트한 문서의 Text Unit이 Neo4j에 임베딩과 함께 저장된다
- [ ] 의미적으로 관련된 쿼리로 벡터 검색 시 해당 Text Unit이 반환된다
- [ ] 벡터 검색이 tenant 스코프로 격리된다
- [ ] 실제 Neo4j 벡터 인덱스 + 실제 bge-m3로 검증(결정적)
