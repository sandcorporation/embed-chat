# Identity Verification — opt-in HMAC로 visitor_id 위조 차단

## Parent

PRD: `.scratch/embed-chatbot-platform/PRD-public-slug-access.md` (ADR-0011)

## What to build

식별된 Visitor의 `visitor_id` 위조를 막는 선택적 검증을 추가한다. Tenant별 토글로 켜며, 켜지면 서버가 `HMAC(tenant secret, visitor_id)` 해시를 요구·검증한다.

- **IdentityVerification deep module**: HMAC 계산·검증을 순수 함수로 캡슐화(tenant secret은 TENANT_KEY 파생). 해시는 무상태·무기한.
- **Operator HMAC API**: TENANT_KEY 인증으로 visitor_id의 검증 해시를 발급(Tenant가 유저당 1회 받아 캐시).
- **opt-in 토글**: TenantConfig 신원검증 요구 불리언(기본 OFF). ON이면 stream 연결 시 무효/누락 해시의 visitor_id를 거부.

## Acceptance criteria

- [ ] HMAC 계산이 같은 (secret, visitor_id)에 멱등이고, 다른 tenant secret이면 다른 해시다
- [ ] Operator HMAC API가 TENANT_KEY 인증으로 해시를 발급한다
- [ ] 그 해시가 stream 연결 검증을 통과한다
- [ ] 토글 ON에서 유효 hash는 연결 허용, 무효/누락 hash는 거부된다
- [ ] 토글 OFF(기본)에서는 평문 visitor_id로 즉시 연결된다
- [ ] 위조 hash로 남의 visitor_id 연결이 거부된다
- [ ] 테스트: HMAC은 결정적 단위, API 발급→stream 검증은 통합
