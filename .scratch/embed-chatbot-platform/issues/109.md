# 109 — 백엔드 Schema 정비: memory/session 라우터 (와이어 불변)

Status: ready-for-agent

## Parent

[PRD-admin-orval-codegen.md](../PRD-admin-orval-codegen.md) · [ADR-0014](../../../docs/adr/0014-admin-orval-openapi-codegen.md)

## What to build

memory 및 session 라우터에서 `dict`/`list`/무 response인 엔드포인트(visitor memory 목록/수정, session 메시지/checkpoint 등)에 `Schema`를 부여한다. **와이어 포맷 불변 제약**. checkpoint는 404→null 분기가 있으니 응답 계약(존재/부재)을 정확히 기술. 재생성으로 타입 구체화.

## Acceptance criteria

- [ ] memory/session 라우터의 dict/list/무 response 엔드포인트에 응답 Schema 부여
- [ ] checkpoint의 존재/부재(404) 응답 계약을 정확히 모델링(기존 동작 불변)
- [ ] **와이어 포맷 불변**: 정비 전과 동일 JSON 반환(pytest 회귀)
- [ ] 재생성 후 산출물 커밋
- [ ] 기존 memory/visitors 백엔드 테스트 GREEN(풀스택 docker)

## Blocked by
