## What to build

어드민 프론트엔드의 `api.js`에 Visitors 탭이 사용할 네 가지 API 함수를 추가한다.
백엔드 엔드포인트는 이미 구현되어 있으며, 프론트엔드 연결만 남아있다.

추가할 함수:

- `listVisitors(agentToken, search?)` → `GET /api/tenant/visitors/?search=<keyword>`
  - `search`가 없으면 쿼리 파라미터를 생략
- `listVisitorSessions(agentToken, visitorId)` → `GET /api/tenant/visitors/{visitorId}/sessions/`
- `getSessionMessages(agentToken, sessionId)` → `GET /api/tenant/sessions/{sessionId}/messages/`
- `getSessionCheckpoint(agentToken, sessionId)` → `GET /api/tenant/sessions/{sessionId}/checkpoint`
  - 404 응답 시 에러를 던지지 않고 `null`을 반환한다 (checkpoint 없는 세션 정상 처리)

## Acceptance criteria

- [ ] `listVisitors(agentToken)` 호출 시 `GET /api/tenant/visitors/`로 요청
- [ ] `listVisitors(agentToken, "foo")` 호출 시 `GET /api/tenant/visitors/?search=foo`로 요청
- [ ] `listVisitorSessions(agentToken, visitorId)` 호출 시 올바른 URL로 요청, 배열 반환
- [ ] `getSessionMessages(agentToken, sessionId)` 호출 시 올바른 URL로 요청, 배열 반환
- [ ] `getSessionCheckpoint(agentToken, sessionId)` 호출 시 200이면 JSON 반환, 404이면 `null` 반환
