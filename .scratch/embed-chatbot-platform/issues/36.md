# 36 — Visitors 탭 — Visitor 목록 API + UI

Status: ready-for-agent

## Parent

`.scratch/embed-chatbot-platform/PRD-conversation-visibility.md`

## What to build

Memory 탭을 "Visitors" 탭으로 교체한다. 새 API `GET /api/tenant/visitors/`를 추가해 해당 Tenant의 고유 Visitor 목록을 최근 활동순으로 반환. `search` 쿼리 파라미터로 visitor_id 부분 검색 지원. 반환 형태: `[{visitor_id, session_count, last_active_at}]`. 어드민 UI에서 Memory 탭을 제거하고 Visitors 탭을 추가. 탭에는 검색창과 Visitor 목록 테이블 표시.

## Acceptance criteria

- [ ] `GET /api/tenant/visitors/` 가 Tenant 소속 Visitor 목록을 반환함
- [ ] `?search=xxx` 파라미터로 visitor_id 부분 일치 필터링 가능
- [ ] 응답에 `visitor_id`, `session_count`, `last_active_at` 포함
- [ ] 어드민에서 Memory 탭이 Visitors 탭으로 교체됨
- [ ] Visitor 목록과 검색창이 표시됨

## Blocked by

None - can start immediately
