# 200 — admin UI (주제범위 제어 설정)

Status: ready-for-agent
Labels: ready-for-agent, HITL

## Parent

[PRD-topic-scope-enforcement.md](../PRD-topic-scope-enforcement.md)

## What to build

운영자가 admin 설정 화면에서 주제범위 제어를 켜고 범위·거절 문구를 관리한다.

- 설정 화면에 토글(`topic_scope_enabled`) + 범위 설명(`scope_description`) + (선택) 거절 문구
  (`scope_refusal_message`) 입력.
- 토글 ON 시 범위 설명 필수 — UI 검증(빈 채로 켜면 저장 막고 안내).
- 가이드/플레이스홀더/예시 제공(예: "주문·배송·반품·상품 문의").

## Acceptance criteria

- [ ] 토글·범위 설명·거절 문구를 admin에서 설정·조회
- [ ] 토글 ON + 빈 범위 설명 → UI에서 저장 차단·안내
- [ ] 플레이스홀더/가이드 노출
- [ ] vitest 컴포넌트 테스트(토글 게이팅·검증)
